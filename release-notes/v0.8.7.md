**カンバンのカードが見やすくなり、「未着手 / 進行中 / 完了」をボードごとに細かく分けた独自のステータスを使えるようになりました。**

## ✨ 新機能

### カスタムステータス（状態タグ）
「進行中」の中に「レビュー待ち」「確認中」を作るなど、ボードごとに独自のステータスを追加できます。チームや案件ごとの進め方に合わせて、カンバンの状態をそのまま表せます。

- カンバン上部の **ステータス** から追加・編集。名前・色・どの基本状態（未着手 / 進行中 / 完了）に属するかを設定
- カードの状態ピルのクリックは、従来どおり 未着手 → 進行中 → 完了 を切り替え。細かいステータスは ▾ または右クリックのメニューから選択
- 各列の見出しのメニューから、ステータスごとにカードを絞り込み
- ステータスの名前変更・削除・属する基本状態の変更は、付いているタスクにも自動で反映（Ctrl+Z 1 回で元に戻せます）
- 実体はタグなので、検索・一括編集スクリプト・同期でもそのまま使えます

→ 詳しくは [ヘルプ: タスク](https://yyamada722.github.io/constella/guide/tasks)

## 🛠 改善

- カンバンのカードを 2 段組みにしました。1 段目に状態・優先度・進行中の時間、2 段目にタスク名を全幅で表示するので、長いタスク名も読みやすくなりました。
- サブタスクの追加・編集・メニューのボタンは、カードにマウスを乗せたときだけ右上に表示されるようになり、カードがすっきりしました。
