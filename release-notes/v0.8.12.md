**X（Twitter）のツイートを、画像・動画・リンクごとリサーチに保存できるようになりました。元のツイートが消えても、オフラインでも見直せます。**

## ✨ 新機能

### ツイートを中身ごと保存
気になったツイートを、本文だけでなく画像・動画・GIF・リンクカード・引用ツイートまで Constella の中に残せます。保存した画像や動画はバックアップと他の PC への同期にも含まれます。

- Chrome では、ツイートを開いて拡張のアイコンから保存します。タイムラインでは、ツイートの日時を右クリック →「リンク先をリサーチに保存」でも取り込めます
- Constella の中では、リサーチのホームでツイートの URL を開き、「ツイートとして保存」を押します
- 保存したツイートは一覧に 𝕏 マークが付き、選ぶと保存した内容で表示されます。画像はクリックで拡大、動画はその場で再生できます
- 「ツイート / ライブ」で、保存した内容と X のページ表示を切り替えられます
- ツイート内のリンクは「リサーチに追加」でそのまま登録でき、「ノート化」で本文・画像・リンクをノートにできます
- リサーチ内検索で、ツイートの本文や投稿者名でも探せます

→ 詳しくは [ヘルプ: 各ページの使い方](https://yyamada722.github.io/constella/guide/pages)

## ⚠️ ご注意

- Chrome 拡張を新しい版にするには、Constella を更新したあと `chrome://extensions` で拡張機能を再読み込みしてください。
- 鍵アカウントなど公開されていないツイートは、Chrome でツイートを開いて拡張から保存すると、画面に表示されている本文と画像を保存します（動画はサムネイルのみ）。
- X 側の仕様変更により、ツイートの中身を取得できなくなることがあります。その場合はリンクだけを保存します。
