**ターミナルから `constella` コマンドで、タスクとノートを読み書きできるようになりました。大量の一括処理や、スクリプト・AI ツールからの操作に使えます。**

## ✨ 新機能

### コマンドライン（CLI）
アプリを開いて 1 件ずつ操作しなくても、ターミナルからタスクとノートをまとめて確認・変更できます。シェルスクリプトや、Claude Code などの AI ツールに作業を任せるときの入口としても使えます。

- **タスク**: 一覧（ボード・状態・タグ・キーワード、「期限切れ」などの条件で絞り込み）、追加、変更（状態・期限・タグ・優先度・親タスク など）、削除
- **ノート**: 一覧・検索、本文の取り出し（Markdown ファイルに保存）、追加、本文の差し替え・追記、アーカイブ、削除
- **一括処理**: カンバンの「一括編集」と同じ書き方のスクリプトや、操作を並べた JSON ファイルで、まとめて変更
- **安全のための仕組み**
  - 書き込み系のコマンドは、まず「何が変わるか」のプレビューだけを表示します。`-y` を付けたときにだけ適用されます
  - 1 回のコマンドで行った変更は、アプリで **Ctrl+Z 1 回**でまとめて元に戻せます
  - 複数の変更のうち 1 つでも失敗した場合は、何も変更しません
  - 取得してから変更するまでの間にアプリ側で書き換わっていたら止める指定もできます
- アプリが起動していなければ、コマンドが自動でアプリを起動してから実行します
- Node.js などの追加インストールは不要です（ポータブル版で、アプリを閉じた状態から使う場合を除く）

**はじめかた**: **設定 → コマンドライン (CLI)** に、コマンドの場所と PATH へ追加するためのコマンドが表示されます（コピーボタン付き）。PATH に追加したらターミナルを開き直し、`constella --help` を実行してください。

```
constella tasks --board 開発 --status 進行中
constella task add "設計レビュー" --board 開発 --end 今日+3 -y
constella task script "#backend 期限<今日 -> 進行中" -y
constella note get <id> --raw > memo.md
```

→ 詳しくは [ヘルプ: データとバックアップ](https://yyamada722.github.io/constella/guide/data)
