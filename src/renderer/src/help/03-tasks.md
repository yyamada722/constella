# タスク・ガント

タスクページは「ボード」ごとにタスクを持ち、**カンバン / ガント / カレンダー**の 3 つの表示を切り替えられます。

## ボード

左のパネルでボードを作成します。ダブルクリックで名前変更、色スウォッチでボード色を設定できます。ボード色はガントのフィルターやバーの色ストライプに使われます。

## カンバン表示

「未着手 / 進行中 / 完了」の 3 列にタスクカードが並びます。

- **ステータスはクリックで循環**します（未着手 → 進行中 → 完了）。数秒のカウントダウン内なら続けてクリックして選び直せます。
- カードのドラッグで列間移動・並べ替えができ、**カードを別カードの下半分に重ねるとサブタスク（子）**になります。親タスクの進捗・期間・状態は子から自動集計されます。
- 表示は**階層 / フラット**を切り替え可能。「完了非表示」で終わったタスクを畳めます。
- 優先度（P1〜P4）、開始日・終了日、メモを各カードで編集できます。

### AI 出力やリストから一括追加

「一括でタスクを追加」を開くと、AI に依頼するためのプロンプト雛形が表示されます。AI の回答（JSON またはインデント付きリスト）を貼り付けると、階層構造ごとまとめてタスク化されます。

### タスクとノートをつなぐ

タスク編集の「関連ノート」でノートをリンクすると、タスク選択時に右側へ**ノートパネル**が開き、タスクを見ながらノートを読み書きできます。

### 他プロジェクトへの共有

「他のプロジェクトのガントにも表示する」をオンにすると、そのタスクが**代替タイトル**で他プロジェクトのガントに読み取り専用で表示されます。実名を出さずに「この期間は埋まっている」ことだけ伝えられます。

## ガント表示

タスクの期間を横棒（バー）で表示します。

- **バーをドラッグ**して期間を動かせます。中央ドラッグで全体移動、左端 / 右端で開始日・終了日の変更。1 日単位でスナップします。
- **日付未設定のタスク**は上部に破線のチップで表示され、クリックで「今日 1 日」「今日から 1 週間」を一発割り当て、ドラッグで期間を描いて割り当てもできます。
- バーをクリックすると**その場で編集**（タイトル・状態・日付・メモ・関連ノート）できます。親タスクには子の内訳（完了 / 進行中 / 未着手）が表示されます。
- ズームは**標準 / 3ヶ月 / 半年**の 3 段階。「今日へ」ボタンで現在位置に戻れます。
- 上部の**ボードチップ**で表示するボードを絞り込めます。`Alt`+クリックでそのボードだけを非表示にできます。
- 週末と日本の祝日は背景色で区別されます。期限を過ぎた未完了タスクは赤い尻尾で警告されます。
- 左のタスク名リストでも、ドラッグで並べ替え・親子化ができます。

## カレンダー表示

月のグリッドにタスクをステータス色で表示します。月をまたぐ予定の俯瞰に使えます。

> [!TIP]
> 全プロジェクトを横断した「遅延 / 今日 / 明日 / 近日」の一覧は**ダッシュボード**の「やること」ビューにあります。
