# タスク・ガント

タスクページは「ボード」ごとにタスクを持ち、**カンバン / ガント / カレンダー**の 3 つの表示を切り替えられます。

## ボード

左のパネルでボードを作成します。ダブルクリックで名前変更、色スウォッチでボード色を設定できます。ボード色はガントのフィルターやバーの色ストライプに使われます。

## カンバン表示

「未着手 / 進行中 / 完了」の 3 列にタスクカードが並びます。

- **ステータスはクリックで循環**します（未着手 → 進行中 → 完了）。数秒のカウントダウン内なら続けてクリックして選び直せます。
- カードのドラッグで列間移動・並べ替えができ、**カードを別カードの下半分に重ねるとサブタスク（子）**になります。親タスクの進捗・期間・状態は子から自動集計されます。
- 表示は**階層 / フラット**を切り替え可能。「完了非表示」で終わったタスクを畳めます。
- 優先度（P1〜P4）、開始日・終了日、メモを各カードで編集できます。
- カードは「ステータス・進行中時間 → タスク名 → 説明 → タグ」の段組みです。タスク名はカード幅いっぱいに使い、長ければ折り返します。「サブタスク追加 / 編集 / メニュー」ボタンはホバーしたときだけ右上に重なって出ます。

### カスタムステータス（状態タグ）

上部の**ステータス**ボタンから、基本状態（未着手 / 進行中 / 完了）を細分化するステータスをボードごとに登録できます（例: 進行中 › 作業中 / レビュー待ち、未着手 › 保留）。

- 実体は**タグ**です。タスクにはそのステータス名のタグが付き、検索・一括編集スクリプト・同期でもタグとして扱われます。既存のタグ名で登録すれば、そのタグを持つタスクがそのままステータスになります。
- ステータスピルの**クリックは基本状態だけを循環**します（未着手 → 進行中 → 完了。細分が増えても長くなりません）。細分ステータスはピル右の **▾**（または右クリック）のプルダウンから選びます。編集画面の「状態」欄でも選べます。
- カンバンの列は従来どおり 3 列です。列見出しの下のプルダウンで、その列をステータス別に絞り込めます（件数付き）。
- 管理画面で名前・**色（丸をクリックで任意の色）**・基本状態を変更できます。名前を変えるとタスク側のタグも追従し、削除するとタスクからも外れます。
- ドラッグやガントなどで基本状態が変わると、元の基本状態の状態タグは自動で外れます。基本状態が違うタスクに付いている同名のタグは、普通のタグとして扱われます。
- 列をステータスで絞り込んでいるときは、該当タスクを階層なしの一覧で表示し、「＋ 追加」はそのステータス付きで作成します。

### 進行中の累計時間

タスクが**「進行中」だった時間は自動で累計**されます。進行中にした瞬間から計測が始まり、別のステータスに変えるとそこまでの時間が積み上がります（何度往復しても合算）。カードには ⏱ チップで、編集画面には「進行中 累計」行で表示され、鉛筆アイコンから**時間・分を手修正**できます。計測中に手修正すると、その値から改めて計測が続きます。

### AI 出力やリストから一括追加

「一括でタスクを追加」を開くと、AI に依頼するためのプロンプト雛形が表示されます。AI の回答（JSON またはインデント付きリスト）を貼り付けると、階層構造ごとまとめてタスク化されます。

### スクリプトで状態を一括編集

カンバンの「一括編集」を開くと、条件に合うタスクの状態（未着手 / 進行中 / 完了）をまとめて変更できます。1 行 1 ルールで、`状態: 対象, 対象…` か `対象 -> 状態` の形で書きます。

```
完了: 設計レビュー, "API 実装"
#backend @未着手 -> 進行中
期限<今日 @未着手 -> 進行中
/^テスト/ +子 -> 完了
```

- **対象の書き方**: タイトルの一部（`*` でワイルドカード）、`"完全一致"`、`/正規表現/`、`id:ID`、`#タグ`、`@未着手` などの現在の状態、`期限<今日` / `開始>=2026-10-01` などの日付、`P1`〜`P4` の優先度。空白区切りは AND、カンマ区切りは OR、`*` はすべてのタスク。`+子` でそのタスクの子孫も対象になります。
- 変更内容は適用前に**プレビュー**され、該当なしの行は警告されます。適用は 1 回の `Ctrl+Z` でまとめて戻せます。
- 「このボード / 全ボード」で範囲を切り替えられます。
- 「AI 用プロンプトをコピー」でタスク一覧と文法を含むプロンプトをコピーし、AI にスクリプトを書いてもらうこともできます（JSON 配列 `[{ "title": "…", "status": "done" }]` の貼り付けにも対応）。

### タスクとノートをつなぐ

タスク編集の「関連ノート」でノートをリンクすると、タスク選択時に右側へ**ノートパネル**が開き、タスクを見ながらノートを読み書きできます。

### 他プロジェクトへの共有

「他のプロジェクトのガントにも表示する」をオンにすると、そのタスクが**代替タイトル**で他プロジェクトのガントに読み取り専用で表示されます。実名を出さずに「この期間は埋まっている」ことだけ伝えられます。

## ガント表示

タスクの期間を横棒（バー）で表示します。

- **バーをドラッグ**して期間を動かせます。中央ドラッグで全体移動、左端 / 右端で開始日・終了日の変更。1 日単位でスナップします。
- **日付未設定のタスク**は上部に破線のチップで表示され、クリックで「今日 1 日」「今日から 1 週間」を一発割り当て、ドラッグで期間を描いて割り当てもできます。
- バーをクリックすると**その場で編集**（タイトル・状態・日付・メモ・関連ノート）できます。親タスクには子の内訳（完了 / 進行中 / 未着手）が表示されます。
- ズームは**標準 / 3ヶ月 / 半年**の 3 段階。「今日へ」ボタンで現在位置に戻れます。
- 上部の**ボードチップ**で表示するボードを絞り込めます。`Alt`+クリックでそのボードだけを非表示にできます。
- 週末と日本の祝日は背景色で区別されます。期限を過ぎた未完了タスクは赤い尻尾で警告されます。
- 左のタスク名リストでも、ドラッグで並べ替え・親子化ができます。

## カレンダー表示

月のグリッドにタスクをステータス色で表示します。月をまたぐ予定の俯瞰に使えます。

> [!TIP]
> 全プロジェクトを横断した「遅延 / 今日 / 明日 / 近日」の一覧は**ダッシュボード**の「やること」ビューにあります。
