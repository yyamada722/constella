# ノート

Markdown で書くメモ・議事録・ドキュメントのページです。書いたそばから整形表示され、PDF やスライドにもなります。

## 整理のしかた

- 左のリストで**フォルダー**を作り、ドラッグ＆ドロップでノートを仕分けます。フォルダーは入れ子にでき、色も付けられます。
- よく使うノートは**ピン留め**で先頭に固定。使い終わったノートは**アーカイブ**で一覧から退避できます（完全削除も可能）。
- 上部の検索ボックスはタイトル・本文・タグを対象に絞り込みます。並び順は「更新順 / 作成順 / タイトル」から選べます。

## 編集画面

ツールバーで表示モードを切り替えます。

| モード | 内容 |
| --- | --- |
| 編集 | Markdown ソースだけを表示 |
| 分割 | 左にソース、右にプレビュー |
| プレビュー | 整形結果だけを表示 |

文字サイズは `+` / `−` ボタンで調整できます。ツールバーには太字・見出し・リスト・表・コードブロックなどのワンクリック挿入ボタンが並び、編集中に**右クリック**すると「記法を挿入」メニューからさらに多くの部品（数式・Mermaid 図・コールアウト・脚注・今日の日付・議事録 / 日報テンプレートなど）を挿入できます。

## 使える記法

基本の Markdown（見出し `#`、リスト `-`、番号リスト `1.`、チェックリスト、表、引用 `>`、コードブロック）に加えて、次の拡張が使えます。

| 記法 | 結果 |
| --- | --- |
| `==重要==` | ==重要== のようにハイライト |
| `> [!NOTE] 補足` | 色付きのコールアウトボックス（NOTE / TIP / IMPORTANT / WARNING / CAUTION） |
| `$E=mc^2$`・`$$…$$` | 数式（KaTeX） |
| ```` ```mermaid ```` コードブロック | フローチャートなどの図（Mermaid） |
| `[[` カード名 `]]` | キャンバスのカードへジャンプする wiki リンク |

> [!NOTE]
> 文中の改行は Markdown の標準仕様どおり、行末にスペース 2 個か `\` を置いたときだけ改行されます。段落を分けるには空行を挟みます。

## 貼り付けが賢い

- **画像**をコピーして `Ctrl+V` → そのまま画像として挿入されます。
- **URL** をテキスト選択中に貼り付け → 選択部分がリンクになります。
- **Web ページや Excel の表**を貼り付け → Markdown の書式・表に自動変換されます。変換したくないときは `Ctrl+Shift+V` でプレーン貼り付け。
- ツールバーの添付ボタンから PDF・画像・動画を**添付**して、ノート内でインラインプレビューできます。

## 検索・置換とアウトライン

- `Ctrl+F` でノート内検索、`Ctrl+H` で置換（1 件ずつ / すべて置換）。
- ツールバーの**アウトライン**ボタンで見出しの目次を表示し、クリックでジャンプできます。

## 書き出しとスライドショー

- **Markdown (.md)** / **PDF** に書き出せます。PDF は A4 の文書レイアウトです。
- 本文を `---`（水平線）で区切っておくと、**スライドショー**ボタンで 16:9 のスライドとして全画面再生できます。スライドの PDF 書き出しも可能です。

## 他プロジェクトとの共有

ノートの「共有」をオンにすると、他のプロジェクトから「参照を追加」でそのノートを読めるようになります。実体はひとつ（編集は元のノート側で行う）なので、プロジェクトをまたぐ共通資料の置き場に便利です。
