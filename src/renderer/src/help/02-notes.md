# ノート

Markdown で書くメモ・議事録・ドキュメントのページです。書いたそばから整形表示され、PDF やスライドにもなります。

## 整理のしかた

- 左のリストで**フォルダー**を作り、ドラッグ＆ドロップでノートを仕分けます。フォルダーは入れ子にでき、色も付けられます。フォルダー行にマウスを乗せると現れる **＋** ボタンで、そのフォルダーの中に直接ノートを作成できます。
- リスト上部の **⇤** ボタンでノートリスト全体を畳めます。畳んだ状態でもマウスを乗せると一時的に展開され、もう一度ボタンを押すと固定表示に戻ります。
- よく使うノートは**ピン留め**で先頭に固定。使い終わったノートは**アーカイブ**で一覧から退避できます（完全削除も可能）。
- 上部の検索ボックスはタイトル・本文・タグを対象に絞り込みます。並び順は「更新順 / 作成順 / タイトル」から選べます。

## 編集画面

ツールバーで表示モードを切り替えます。

| モード | 内容 |
| --- | --- |
| 編集 | Markdown ソースだけを表示 |
| ライブ | Typora 風。中央寄せのビューで、クリックしたブロックだけソース編集、それ以外は整形表示。`Esc` で全ブロックをプレビューに戻し、ブロックの先頭/末尾で `↑` / `↓` を押すと前後のブロックへ移動します |
| 分割 | 左にソース、右にプレビュー。両側のスクロールが同期します |
| プレビュー | 整形結果だけを、ライブと同じ中央寄せで表示 |

`Ctrl+Shift+E` で編集 ⇔ プレビューを素早く切り替えられます。切り替えてもスクロール位置は保たれ、編集に戻るとキャレットは見えている行に置かれます。右端の**ミニマップ**で長いノートの現在位置を確認でき、クリックでジャンプできます。

文字サイズは `+` / `−` ボタンで調整できます。その隣の**パレット**ボタンで**執筆テーマ**を切り替えられます。**カラー**（標準 / クリーン / セピア / 生成り / ポップ / ナイト）と**フォント**（ゴシック / 明朝 / 手書き / 等幅）は独立して選べ、自由に組み合わせられます。クリーンとナイトは Typora の Ladder テーマ（ライト / ダーク）、ポップは Sneh テーマがモチーフで、「クリーン or ナイト × 手書き」「ポップ × 手書き」あたりが再現度の高い組み合わせです。執筆面（エディタとプレビュー）だけの紙色・フォントが変わり、アプリ全体のテーマとは独立です。ツールバーには太字・見出し・リスト・表・コードブロックなどのワンクリック挿入ボタンが並び、編集中に**右クリック**すると「記法を挿入」メニューからさらに多くの部品（数式・Mermaid 図・コールアウト・脚注・今日の日付・議事録 / 日報テンプレートなど）を挿入できます。

## 使える記法

基本の Markdown（見出し `#`、リスト `-`、番号リスト `1.`、チェックリスト、表、引用 `>`、コードブロック）に加えて、次の拡張が使えます。

| 記法 | 結果 |
| --- | --- |
| `==重要==` | ==重要== のようにハイライト |
| `> [!NOTE] 補足` | 色付きのコールアウトボックス（NOTE / TIP / IMPORTANT / WARNING / CAUTION） |
| `$E=mc^2$`・`$$…$$` | 数式（KaTeX） |
| ```` ```mermaid ```` コードブロック | フローチャートなどの図（Mermaid） |
| `[[` カード名 `]]` | キャンバスのカードへジャンプする wiki リンク |
| `[^1]` と `[^1]: 内容` | 脚注 — ページ末尾にまとまり、番号クリックで行き来できます |

> [!NOTE]
> 文中の改行は Markdown の標準仕様どおり、行末にスペース 2 個か `\` を置いたときだけ改行されます。段落を分けるには空行を挟みます。

## 貼り付けが賢い

- **画像**をコピーして `Ctrl+V` → そのまま画像として挿入されます。
- **URL** をテキスト選択中に貼り付け → 選択部分がリンクになります。
- **Web ページや Excel の表**を貼り付け → Markdown の書式・表に自動変換されます。変換したくないときは `Ctrl+Shift+V` でプレーン貼り付け。
- ノート下部の**付随資料**に PDF・画像・動画を添付できます。添付は**ファイル**ページのライブラリに登録され、ノートからは参照として表示されます。グループ（先方 / 自分 など）で仕分けでき、その場でプレビュー（PDF・画像はズーム可）できます。

## 検索・置換とアウトライン

- `Ctrl+F` でノート内検索、`Ctrl+H` で置換（1 件ずつ / すべて置換）。
- ツールバーの**アウトライン**ボタンで見出しの目次を表示し、クリックでジャンプできます。

## 読み込みと書き出し・スライドショー

- リスト上部の**読み込み**ボタンから、外部のテキストファイル（.md / .txt、複数選択可）をノートとして取り込めます。Markdown の先頭見出しや、本アプリで書き出した .md の frontmatter（タイトル・タグ）は自動で復元されます。
- **Markdown (.md)** / **PDF** に書き出せます。PDF は A4 の文書レイアウトです。
- 本文を `---`（水平線）で区切っておくと、**スライドショー**ボタンで 16:9 のスライドとして全画面再生できます。スライドの PDF 書き出しも可能です。

## 他プロジェクトとの共有

ノートの「共有」をオンにすると、他のプロジェクトから「参照を追加」でそのノートを読めるようになります。実体はひとつ（編集は元のノート側で行う）なので、プロジェクトをまたぐ共通資料の置き場に便利です。
