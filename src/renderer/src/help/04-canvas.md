# キャンバス

カード・矢印・手書きを自由に配置できる無限ボードです。資料集め、構成図、企画の発散など、なんでも広げられます。

## ボードとタブ

キャンバスは**ボード（大分類）→ タブ（小分類）**の 2 段で整理します。左パネルでボードを追加し、その中にタブを作ります。タブはドラッグで別ボードへ移動できます。

## カードの種類

ツールバーの追加メニューから配置します。主なもの:

| カード | 内容 |
| --- | --- |
| テキスト | Markdown 本文。複数ページを持てる |
| メモ / TODO / ノート | 実際のタスクやノートと**ライブ連動**（片方を編集するともう片方も更新） |
| Web ページ | URL を埋め込み表示（YouTube などは埋め込みに自動変換） |
| PDF / 画像 / 動画 / 音声 | ファイルをそのまま配置。PDF はページ送り・見開き・ズーム、画像はズーム/トリミング、動画はブックマークやフレーム書き出し、音声は波形表示に対応。ファイルページのライブラリからも配置できます |
| 連番再生 | 複数画像をパラパラ再生（オニオンスキン付き） |
| スケッチ / 路線図 | スケッチページ・路線図の内容を読み取り専用でミラー表示 |
| タスク下書き | あとでまとめてタスク化するための下書き（後述） |
| キャンバスリンク | 別のタブへジャンプするショートカット（プレビュー付き） |
| シェイプ | 四角・円・ひし形・円柱(DB)・クラウド・人・サーバーなど構成図用の図形 14 種 |

画像・PDF・動画はファイルの**ドラッグ＆ドロップや貼り付け**でも配置できます。

## ツール

ツールバーで持ち替えます: **選択 / 矢印 / グループ / ペン / 消しゴム / ラベル / タスク下書き / 線路**。

- **矢印**: カードからカードへドラッグ。カードの 8 方向ポートに吸着し、曲げ点・ラベル・色・太さを設定できます。矢印はカードと一緒に範囲選択・`Shift`+クリックで複数選択でき、まとめて移動・複製・削除できます。
- **ポイント指し**: `Alt` を押しながら矢印の先端をカードの中へ落とすと、枠ではなく**その一点**（画像の特定の場所など）を指します。始点も `Alt` を押しながらカード内で描き始めれば固定できます。固定した端は小さなリングで示され、カードを動かしたり大きさを変えても追従します。既存の矢印の端をドラッグして `Alt` で落としても同じです。解除は右クリック →「ポイント固定を解除」。
- **グループ**: ドラッグで枠を描いてカードをまとめます（`Ctrl+G` でも）。枠ごと移動できます。枠の名前タブは常にカードより手前に表示されます。右クリック（または上部ツールバー）から枠の色・背景の濃さ・見出しの表示 / 非表示・カードより手前 / 奥・グループ同士の前後（最前面へ / 最背面へ）を設定できます。見出しを隠したグループは枠線をつかんで移動・選択できます。
- **ペン / 消しゴム**: 手書きの書き込み。消しゴムは「なぞった部分だけ」と「線ごと」の 2 方式。
- **線路**: キャンバス上に直接、路線と駅を描けます。駅には「計画中 / 建設中 / 開業」の状態を付けられます。

## 整えるための機能

- **整列**: 複数選択して左右・上下揃え、3 個以上なら均等配置。
- **色**: カードに淡色 / 濃色のパレットから色を付けられます。前面 / 背面の並び替えも可能。
- **ヘッダー非表示**: 画像・動画・PDF・音声・連番カードは右クリック →「ヘッダーを隠す」でタイトル部を消し、中身だけを見せられます。カードにホバーするとカードの**すぐ上**に半透明の掴みストリップが現れ、そこから移動・名前変更・ファイル差し替え・「ヘッダーを表示」で戻せます（画像カードは画像そのものを掴んで移動できます）。ストリップはカードの外にあるので、画像右上の「切り抜き」などのボタンを隠しません。
- **角丸のオン / オフ**: 右クリック →「角丸をなくす / 角丸にする」、またはプロパティパネルでカードごとに切り替えられます（複数選択でまとめて可）。
- **画像カード**: 画像にホバーすると右上に「コピー」「書き出し」「切り抜き」のボタンが出ます。右クリックメニューにも「画像をコピー」「画像を書き出し…」「画像の比率に合わせる」があります。
  - **画像をコピー**: 表示中の範囲（切り抜き適用後）を PNG として OS のクリップボードへ。画像カード 1 枚だけを選んで `Ctrl+C` しても同じくコピーされ、他のアプリにそのまま貼り付けられます。
  - **画像を書き出し…**: 切り抜きなしなら元ファイル（JPEG / GIF などはそのまま）、切り抜きありなら表示範囲の PNG を保存します。
  - **画像の比率に合わせる**: いまの幅のまま、画像（切り抜き後）の縦横比にカードの高さを合わせます。複数の画像カードを選んで右クリックすればまとめて揃えられます（1 回の取り消しで戻せます）。
- **名前の変更**: ヘッダーをダブルクリック、右クリック →「名前を変更」、または右側のプロパティパネルのタイトル欄で変えられます。
- **メモ → 新規ノート**: メモカードに書いた内容は「新規作成」でノートを作ったときそのまま転記され、1 行目がタイトル候補になります。
- **表示**: ミニマップ、グリッドスナップ、全体表示、キャンバス / リスト表示切替。
- **編集ロック**: 閲覧専用にして誤操作を防ぎます（カード単位のロックも可能）。
- **検索**: 「このキャンバス内を検索」でカードを探せます。

## タスク下書き → 一括タスク化

「タスク下書き」カードを散布し、`Tab`（子）/ `Enter`（兄弟）で素早く連鎖させ、矢印で親 → 子をつないでから**タスク化**ボタンを押すと、構造ごと実タスクに一括変換されます。「大体いつ」チップで時期の目安（上旬 / 中旬 / 下旬など）も引き継げます。カレンダーボタン（「今月」）で**対象の月**（○年○月）も指定でき、たとえば「11月・下旬」のように月をまたいだ目安が期日になります。月だけ選んでチップ未選択の場合は**その月の月末**が期日目安になります。未指定なら今月（過ぎていれば翌月）に自動で読み替えます。

## 書き出し

- **PNG**: 現在のタブを画像に。
- **共有用 HTML**: パン / ズーム・動画再生までできる単一 HTML ファイルに書き出し。アプリを持っていない相手にそのまま渡せます（動画の埋め込み容量は選択可能）。
- **JSON**: 現在のタブのデータを書き出し。
