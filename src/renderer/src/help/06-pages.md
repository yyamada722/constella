# その他のページ

## ダッシュボード

全プロジェクトを横断してタスクの状況を一望します。表示は 3 種類:

- **やること** — 全タスクを「遅延 / 今日 / 明日 / 近日（約 1 週間）」に仕分けて表示。行をクリックすると該当タスクへ飛べます。
- **ガント** — 全プロジェクトのガントをまとめて表示。
- **プロジェクト別** — プロジェクトごとの進捗サマリー。

ヘッダーのベルには遅延・今日のタスク件数が常に表示され、クリックで「やること」へ移動します。プロジェクトの絞り込みと「要対応順」の並び替えにも対応しています。

## フロー

ノードをつないで段取りを図にするページです。**ダブルクリック**でノード追加、`Tab` で子・`Enter` で兄弟を素早く展開、ノード下の **● を下へドラッグ**して親 → 子をつなぎます。画像やメモのノードも置けます。

各ノードには「大体いつ」（8月上旬、など）の目安を付けられ、**タスク化**ボタンで図の構造ごと実タスクへ一括変換できます。変換後もノードとタスクは連動し、状態がドットで表示されます。

## リサーチ

内蔵ブラウザで調べ物をするページです。表示中のページを**ブックマーク**として保存し、フォルダー・タグ・色で整理できます。外部ブラウザで開く、JSON への書き出しにも対応しています。

ブックマークはツールバーの**クリップ保存**ボタンで、表示中のページを丸ごと（画像・スタイル込み）この PC に保存できます。保存後は URL バー横の**ライブ / クリップ**切り替えで、インターネットに接続していなくても保存時の状態のままページを閲覧できます。クリップを持つブックマークには一覧に緑のマークが付きます。クリップファイルは端末ローカルに保存されるため、同期先の別マシンには持ち出されません。

クリップ表示中のバナーにある **Markdown化** ボタンで、クリップの本文を Markdown に変換できます。見出し・リスト・表・リンクを保ったまま、**ノートとして作成**（出典 URL・クリップ日付き）するか、**クリップボードにコピー**するかを選べます。

### Chrome から登録する

Chrome 拡張を入れると、Chrome で見ているページをそのままリサーチに登録できます。

1. **設定 → ブラウザ連携**の「拡張のフォルダを開く」でフォルダの場所を確認します
2. Chrome の `chrome://extensions` でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」でそのフォルダを選びます
3. 拡張のアイコンをクリックし、設定画面の**接続コード**を貼り付けます

アイコン（`Alt`+`Shift`+`C`）からプロジェクト・フォルダー・メモ・タグを指定して保存できます（`Ctrl`+`Enter` で保存）。タグはこれまで使ったものをクリックで選べ、新しいタグは入力して `Enter` で追加できます。保存先は直近に使ったプロジェクトとフォルダーを覚えています。**クリップも保存**をオンにすると、Chrome でログインしているページも丸ごと保存できます。右クリックメニューからは、ページやリンク先を直近の保存先へすぐ登録できます。

Constella が起動していないあいだに保存したページ（クリップなし）は Chrome に溜めておき、次に起動したときに登録します。接続コードは**再発行**すると以前のコードが無効になります。

### X（Twitter）のツイートを残す

ツイートを保存すると、本文・投稿者・日時に加えて**画像・動画・GIF・リンクカード・引用ツイート**まで取り込み、Constella の中に保存します。元のツイートが削除されても、インターネットに接続していなくても見直せます（取り込んだ画像・動画はバックアップと同期の対象です）。

- **Chrome から**: ツイートを開いて拡張のアイコンから保存します。タイムラインでは、各ツイートの日時リンクを右クリック →「リンク先をリサーチに保存」でも取り込めます
- **Constella の中で**: ホームの URL バーにツイートの URL を入れて開き、**ツイートとして保存**を押します。リンクだけ保存済みのツイートは、URL バー横の**ツイートを取り込む**で中身を取り込めます

取り込んだツイートは一覧に **𝕏** マークが付き、選ぶと保存した内容で表示されます（**ツイート / ライブ**で X のページ表示と切り替え）。画像はクリックで拡大、動画はその場で再生できます。ツイート内のリンクは**リサーチに追加**でそのまま登録でき、**ノート化**で本文・画像・リンクを Markdown のノートにできます。リサーチ内検索はツイートの本文・投稿者名でも探せます。

鍵アカウントなど公開されていないツイートは、Chrome 拡張でツイートを開いて保存すると、ページに表示されている本文と画像を取り込みます（この場合、動画はサムネイルのみ）。

## ファイル

プロジェクトの写真・PDF・動画・音声を一か所で管理する**ファイルライブラリ**です。フォルダー・タグ・コメントで整理し、グリッド / リストで閲覧、クリックでプレビュー（PDF・画像はズーム、音声は波形プレイヤー）。Word（.docx）・Excel（.xlsx / .xls / .ods、シート切替付き）・PowerPoint（.pptx）もアプリ内で読み取り専用プレビューできます（オフラインで描画。レイアウトは本家 Office と多少異なるため、正確に見たいときは「OSのアプリで開く」を使ってください。旧形式の .doc / .ppt は非対応）。

- ノートの付随資料、タスクの資料リンク、キャンバスのカードはすべてここのファイルへの**参照**です。「使用先」からどこで使われているかへジャンプでき、どこからも参照されていないファイルは「未使用」で掃除できます
- **新しい版をアップロード**すると参照はそのまま差し替わり、旧版は履歴に残ります
- NAS などのファイルは**サーバー参照**として取り込まずに登録でき、他のプロジェクトにも「参照」として表示できます

## スケッチ

手書き専用のホワイトボードです。ペン（8 色 × 4 太さ）と消しゴム（なぞった部分だけ / 線ごと）で描き、**PNG / SVG** に書き出せます。描いたスケッチはキャンバスに「スケッチカード」としてライブ表示できます。

## 路線図

プロジェクトの工程を**路線図のように**描くページです。路線（ライン）に駅（マイルストーン）を並べ、駅には「未着手 / 進行中 / 完了」の状態と 6 種の形を設定できます。複数路線に属する駅は乗換駅として表示されます。

路線上には**電車**を走らせることができ、進捗に応じて位置が動きます。エリア枠・テキストラベル・画像も配置でき、1 プロジェクトに複数の路線図（プラン）を持てます。駅はキャンバスのカードと相互リンクできます。

## 検索

**ノート / タスク / リサーチ / カード / ラベル / 駅** の 6 種類を横断して検索します。マッチ箇所はハイライトされ、クリックでそのページの該当箇所へジャンプします。
