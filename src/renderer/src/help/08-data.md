# データとバックアップ

## データの保存場所

Constella のデータは既定では**お使いの PC の中**だけに保存されます（Constella が外部のサーバーへ送信することはありません）。保存は自動で、閉じる前に保存操作は不要です。

> [!NOTE]
> ご自身で**同期フォルダを設定した場合**や**バックアップ・作業ファイルを書き出した場合**は、その保存先（OneDrive などのクラウドドライブや NAS を指定していればそこ）にもデータのコピーが置かれます。

内部では保存のたびに前世代のコピーを残し、さらに**日次バックアップを 14 世代**保持しています。万一データベースが壊れても、起動時に自動で復旧候補から復元されます。

## バックアップの書き出し / 読み込み

サイドバー下部の**設定 / バックアップ**メニューから:

- **バックアップを書き出し** — 全プロジェクトのデータと添付ファイルを 1 つの JSON ファイルに書き出します。メニューに「最終書き出し」の日時が表示されるので、目安にしてください。
- **バックアップを読み込み** — 書き出した JSON から復元します。PC の買い替えや、別 PC への引っ越しにも使えます。

> [!IMPORTANT]
> 自動バックアップは同じ PC 内にあります。PC の故障に備えるには、書き出した JSON を別のドライブやクラウドストレージに定期的に保管してください。

## ファイルの実体

**ファイル**ページに登録した写真・PDF などの実体は、ノートやタスクの添付も含めてすべてアプリ内のローカルストレージに保存され、バックアップの JSON にも含まれます。「サーバー参照」で登録したファイルはパスだけを保持するので、元のファイルを移動すると開けなくなります。

## 他のマシンと同期 / 作業ファイル

- 自分の**複数の PC** で同じデータを使う → **他のマシンと同期**（同期フォルダ方式）
- **他の人**に作業単位を渡して返してもらう → **作業ファイル（受け渡し）**

どちらも詳しい手順・競合時の動き・トラブルシューティングは「**同期と受け渡し**」の章にまとめています。

## 外部アクセス（LAN 公開）

設定メニューの**外部アクセス**をオンにすると、同じネットワークの iPad やスマホのブラウザから表示された URL で Constella を開けます。別ネットワークや外出先からは、表示に「Tailscale」の行があればその URL を使います。

- 認証はありません。**信頼できるネットワークでのみ**オンにしてください。
- 同時編集は想定していないため、基本は 1 台ずつ使います。デスクトップ側の変更は、リモート側の**同期ボタン**（右下）か画面の再フォーカスで反映されます。
- スマホからは撮影・メモの取り込みに便利なモバイル用画面が表示されます。

## 外観の設定

設定メニューの**外観・コードテーマ…**から:

- **ライト / ダークテーマ**の切り替え
- コードブロックの**ハイライトテーマ**（7 種）
- ピンチズームの**ズーム感度**

## アップデート

新しいバージョンが公開されると自動で通知されます。Windows インストーラー版と Linux の AppImage 版は自動でダウンロードされ、再起動時に適用されます。mac 版・ポータブル版はリリースページへの案内が表示されるので、手動でダウンロードしてください。設定メニューからいつでも手動チェックできます。

## AI アシスタント

デスクトップ版では右下の **AI** ボタンから AI チャットを使えます（Anthropic の API キーの設定が必要です）。回答はそのまま**ノート化 / タスク化**でき、会話履歴も保存されます。API キーは PC 内にのみ保存されます。
