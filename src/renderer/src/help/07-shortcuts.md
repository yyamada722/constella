# キーボードショートカット

Mac では `Ctrl` を `Cmd` に読み替えてください。

## 全般

| キー | 動作 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す（どの画面でも） |
| `?` | このヘルプを開く |
| `Esc` | メニュー・選択・ポップアップを閉じる |

## ノート

| キー | 動作 |
| --- | --- |
| `Ctrl+F` | ノート内を検索 |
| `Ctrl+H` | ノート内を検索・置換（`Enter` 次へ / `Shift+Enter` 前へ） |

### エディタ内（ノート・計画・キャンバスのテキストカード共通）

| キー | 動作 |
| --- | --- |
| `Ctrl+B` / `Ctrl+I` | **太字** / *斜体* |
| `Ctrl+E` | インラインコード |
| `Ctrl+K` | リンクを挿入（URL を選択範囲に貼ってもリンク化） |
| `Ctrl+Shift+X` | 取り消し線 |
| `Ctrl+V` | 貼り付け（画像はそのまま画像に、表や HTML は Markdown に変換） |
| `Ctrl+Shift+V` | 書式変換せずプレーンテキストで貼り付け |
| `Tab` / `Shift+Tab` | リストのインデント / アウトデント（表の中ではセル移動） |
| 右クリック | 記法挿入メニュー（表・数式・コールアウト・テンプレートなど） |

## キャンバス

| キー | 動作 |
| --- | --- |
| ホイール | ズーム |
| `Space`+ドラッグ / 中ボタンドラッグ | 画面を移動（パン） |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Ctrl+A` | すべて選択 |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+D` | コピー / 貼り付け / 複製 |
| `Ctrl+G` / `Ctrl+Shift+G` | グループ化 / グループ解除 |
| 矢印キー（`+Shift`） | 選択カードを移動（大きく移動） |
| `Tab` / `Enter` | タスク下書きの子 / 兄弟カードを追加 |
| `Delete` / `Backspace` | 選択を削除 |
| `Esc` | 選択・ツールを解除 |

## フロー

| キー | 動作 |
| --- | --- |
| ダブルクリック | ノードを追加 |
| `Tab` / `Enter` | 子ノード（下）/ 兄弟ノード（右）を追加 |
| ● を下にドラッグ | 親 → 子を接続（空きに落とすと子ノードを新規作成） |
| `Ctrl+G` / `Ctrl+Shift+G` | グループ化 / 解除 |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+D` | コピー / 貼り付け / 複製 |
| 矢印キー（`+Shift`） | ノードを移動（大きく移動） |
| `Space`+ドラッグ | パン、`Ctrl`+ホイールでズーム |
| 右クリック | 追加・削除メニュー |

## スケッチ

| キー | 動作 |
| --- | --- |
| ホイール | ズーム |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Ctrl+0` | 表示をリセット（全体表示） |

## 路線図

| キー | 動作 |
| --- | --- |
| `A` | 駅の追加モード（`Esc` で終了） |
| `Delete` / `Backspace` | 選択した駅を削除 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 元に戻す / やり直す |
| `Esc` | 選択・モードを解除 |

## スライドショー（ノートの `---` 区切り再生）

| キー | 動作 |
| --- | --- |
| `→` `Space` `PageDown` | 次のスライド（画面右側クリックでも） |
| `←` `PageUp` | 前のスライド（画面左側クリックでも） |
| `Home` / `End` | 最初 / 最後のスライドへ |
| `Esc` | 終了 |

## 計画の記法（早見）

| 書き方 | 意味 |
| --- | --- |
| `## 2026-08-01` | 日付見出し |
| `> [09:00] shoot 撮影` | 予定行（時刻 + 種別 + 内容） |
| `> [09:00] - [17:00] …` | 時間の範囲 |

詳しくは「計画」の章をご覧ください。
