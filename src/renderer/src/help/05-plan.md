# 計画

出張・ロケハン・イベントの旅程を**テキストで**組むページです。決まった記法で書くと、右側に時系列のタイムラインとして整形され、費用も自動集計されます。

## 基本の書き方

```
## 2026-08-01

> [09:00] flight 羽田へ移動 from 自宅 to 羽田^HND
> [10:30] - [12:00] flight JAL503 from 羽田^HND to 新千歳^CTS
> - price: JPY {28000}
> [pm] shoot 市内ロケハン at 大通公園
> [18:00] hotel チェックイン :: 札幌グランドホテル
```

| 記法 | 意味 |
| --- | --- |
| `## 2026-08-01` | 日付見出し（`@Asia/Tokyo` のようにタイムゾーン指定も可） |
| `> [09:00] shoot 内容` | 予定行。時刻 + 種別 + 内容 |
| `> [09:00] - [17:00] …` | 時間の範囲 |
| `> [am]` / `[pm]` / `[]` | おおまかな時刻・未定 |
| `… from 羽田^HND to 新千歳^CTS` | 出発地 → 到着地（`^` の後は略号バッジ） |
| `… at 場所` / `… :: 場所` | 場所の指定 |
| `> - price: JPY {28000*2}` | 費用。`{ }` 内は計算式が使え、日ごと・全体で自動合計 |
| `> - note: メモ` | 補足メモ |
| `> [!NOTE] 持ち物` | 注意書きボックス（NOTE / TIP / WARNING / CAUTION） |

この一覧は編集画面の **?（記法ヘルプ）ボタン**からいつでも確認できます。新規作成時にはテンプレートが入るので、書き換えながら覚えるのが早いです。

## 予定の種別

種別によってタイムライン上のアイコンと色が変わります。

`flight` `train` `bus` `car` `ferry` `walk`（移動系）/ `hotel` `meal` `cafe`（滞在系）/ `museum` `activity` `shoot` `scan` `location` `meeting` `shopping` `prep`（活動系）

## チケットや資料を添付する

- **添付**: e チケットの PDF や画像をアプリに取り込み、予定行のリンクとして挿入します。プレビューでリンクをクリックすると、その場に PDF・画像が展開されます。
- **サーバー参照**: NAS など上のファイルを取り込まず、パスだけ参照として挿入します（ファイルの実体は元の場所のまま）。
- URL リンクもクリックでインライン展開されます。

## 整理と書き出し

- ノートと同じ操作感の**フォルダー**で計画を整理できます。
- **複製**すると「v2」「v3」と版が採番されるので、案 A / 案 B の比較に便利です。
- **PDF 書き出し**は「本文 → 目次 → 別紙（添付した PDF・画像）」の順に 1 冊へ結合し、目次から各別紙へリンクでジャンプできます。そのまま同行者に配れます。

> [!TIP]
> 表示は「編集 / 分割 / プレビュー」を切り替えられます。書くときは分割、確認や当日は プレビューが便利です。
