# 計画（旅程）記法リファレンス

計画ページは **TripMD（itinerary-md）互換**のテキスト記法で旅程を記述します。ここでは Constella が解釈するすべての要素を説明します。

## 全体の構造

```md
---
title: 札幌ロケハン
timezone: Asia/Tokyo
currency: JPY
---

## 2026-08-01

> [09:00] flight JAL503 from 羽田^HND to 新千歳^CTS
> - price: JPY {28000}
> [pm] shoot 市内ロケハン at 大通公園

## 2026-08-02 @Asia/Tokyo

> [10:00] - [12:00] meeting 打合せ :: 先方オフィス
```

ファイルは次の 3 種類の行でできています。

1. **フロントマター**（先頭の `---` で囲まれたブロック・任意）
2. **日付見出し** `## YYYY-MM-DD`
3. **引用行** `> …` — 予定・メタデータ・注意書き

それ以外の行（見出し・リスト・段落）は普通の Markdown として表示されます。

## フロントマター

| キー | 意味 |
| --- | --- |
| `title` | 計画のタイトル |
| `timezone` | 既定のタイムゾーン（例: `Asia/Tokyo`） |
| `currency` | 通貨コードを省略した `price` の既定通貨（既定: `JPY`） |

## 日付見出し

```md
## 2026-08-01
## 2026-08-02 @Europe/Paris
```

`#`〜`###` のいずれかに `YYYY-MM-DD` を書くと日付の区切りになります。`@タイムゾーン` を付けると、その日の予定に既定のタイムゾーンを指定できます。タイムライン表示では `8/1 (土)` のように曜日付きで表示されます。

## 予定行

```md
> [時刻] 種別 タイトル …
> [開始] - [終了] 種別 タイトル …
```

### 時刻の書き方

| 書き方 | 意味 |
| --- | --- |
| `[09:00]` | 時刻 |
| `[09:00] - [17:00]` | 開始 − 終了の範囲 |
| `[am]` / `[pm]` | 午前 / 午後（時刻未確定） |
| `[]` | 時刻未定 |
| `[09:00+1]` | 翌日（`+N` で N 日後。深夜便の到着などに） |
| `[19:30@Europe/Paris]` | その予定だけ別タイムゾーン |

### 種別

時刻の直後の英単語が**種別**になり、タイムライン上のアイコンと色を決めます。大文字小文字は区別しません。

| 系統 | 種別 |
| --- | --- |
| 移動 | `flight` `train` `bus` `car` `ferry` `walk` |
| 滞在 | `hotel` `meal` `cafe` |
| 活動 | `museum` `activity` `shoot` `scan` `location` `meeting` `shopping` `prep` |

一覧にない単語も種別として受け付けられます（汎用アイコンで表示）。

### 場所の指定

```md
> [09:00] flight JAL503 from 羽田^HND to 新千歳^CTS
> [13:00] shoot 外観撮影 at 時計台
> [18:00] hotel チェックイン :: 札幌グランドホテル
```

| 書き方 | 意味 |
| --- | --- |
| `from 出発地 to 到着地` | 移動の区間。タイムラインでは「出発地 → 到着地」のルート表示 |
| `at 場所` | 場所（`from … to …` がない場合） |
| `:: 場所` | 目的地 / 施設名。タイトルと分けて表示される |
| `場所^略号` | `^` の後ろが略号バッジ（空港コードなど）として表示される |

タイトル部分にはリンク `[名前](URL)` などのインライン Markdown が使えます。

## メタデータ行

予定行の直後に `> - キー: 値` を続けると、その予定に情報を付加できます。

```md
> [09:00] flight JAL503 from 羽田^HND to 新千歳^CTS
> - price: JPY {28000*2}
> - note: eチケットは下のリンク
> - seat: 12A
```

| キー | 意味 |
| --- | --- |
| `price` / `cost` | 費用。日ごと・全体で**通貨別に自動合計**されます |
| `note` | メモ |
| その他 | 任意のキーをそのまま表示 |

### 費用の書き方

| 書き方 | 解釈 |
| --- | --- |
| `JPY 28000` / `EUR 80` | 通貨コード + 金額 |
| `¥28000` / `$120` / `€80` / `£50` / `₩10000` | 通貨記号 + 金額 |
| `28000` | フロントマターの `currency`（既定 JPY）で解釈 |
| `{28000*2}` / `EUR {80*2+15}` | `{ }` の中は四則演算式（数字と `+ - * / ( )` のみ） |

## 注記行

予定行に続けて、メタデータでも予定でもない `> テキスト` を書くと、その予定の注記として表示されます。

```md
> [09:00] shoot 外観撮影 at 時計台
> 三脚は現地で借りる
```

## アラート

```md
> [!NOTE] 持ち物
> 雨具・予備バッテリー
> [!WARNING] 注意
> 駐車場は 17:00 で閉まる
```

`NOTE` / `TIP` / `IMPORTANT` / `WARNING` / `CAUTION` が使えます。続く `>` 行が本文です。

## 添付とリンク

| 書き方 | 動作 |
| --- | --- |
| `[名前](https://…)` | クリックでその場にページをインライン展開 |
| `[チケット.pdf](idb:…)` | ツールバーの**添付**で取り込んだ PDF・画像。クリックでインライン展開 |
| `[資料.pdf](local:\\nas\share\資料.pdf)` | **サーバー参照**。取り込まずパスだけ保持し、クリックで展開 |

添付は PDF 書き出し時に**別紙**として末尾に結合され、目次からリンクで飛べます。

## そのほかの行

日付見出し・引用行以外の行は、見出し（`#`）、リスト（`-` / `*`）、段落として表示されます。日程の前置きや持ち物リストに使えます。
