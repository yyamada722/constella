# よくある質問

## インストール・アップデート

### どのファイルをダウンロードすればいいですか？

[GitHub Releases](https://github.com/yyamada722/constella/releases/latest) から:

| ファイル | 用途 |
| --- | --- |
| `Constella-x.y.z-x64.exe` | Windows インストーラー。**自動アップデート対応**なのでこちらがおすすめ |
| `Constella-x.y.z-portable.exe` | Windows ポータブル版。インストール不要、USB メモリなどから起動可 |
| `Constella-x.y.z-arm64.dmg` | mac（Apple シリコン） |

### Windows で「WindowsによってPCが保護されました」と出ます

コード署名証明書を使っていないための警告です。「詳細情報」→「実行」で起動できます。

### mac で「開発元を検証できません」と出ます

同じく署名の関係です。アプリを右クリック →「開く」で起動するか、システム設定 → プライバシーとセキュリティ から許可してください。

### アップデートはどう届きますか？

起動から数秒後と、その後 4 時間おきに新バージョンを確認します。インストーラー版は自動でダウンロードして次回起動時に適用、ポータブル版 / mac 版はリリースページへの案内が表示されます。設定メニューからいつでも手動で確認できます。

## データ

### データはどこに保存されますか？

Windows は `%APPDATA%\constella\`（`constella.db`）、mac は `~/Library/Application Support/constella/` です。添付した画像・PDF などのファイルはアプリ内のローカルストレージ（IndexedDB）に保存されます。クラウドには送信されません。

### 別の PC に引っ越したい

設定メニューの**バックアップを書き出し**で JSON を作り、新しい PC で**バックアップを読み込み**してください。添付ファイルも含めて復元されます。

### 誤って削除してしまいました

削除直後なら画面下の「元に戻す」トーストか `Ctrl+Z` で戻せます。それより後でも、ノート・プロジェクトは**アーカイブ**に残っている場合があります（完全削除するまで消えません）。

### データベースが壊れたと表示されました

Constella は保存のたびに前世代のコピーを残し、日次バックアップを 14 世代保持しています。起動時に破損を検知すると自動で復旧候補から復元し、画面上部にバナーが表示されます。復元されたデータが古い場合は、書き出しておいた JSON バックアップから読み込んでください。

## 使い方

### Markdown で改行しても 1 行につながってしまう

仕様です。行末に**スペース 2 個**を置くか、空行で段落を分けてください。詳しくは [Markdown 記法リファレンス](/reference/markdown) を参照。

### iPad やスマホから見たい

設定メニューの**外部アクセス**をオンにすると、同じ Wi-Fi 内のブラウザから表示された URL で開けます。認証はないので、信頼できるネットワークでのみ使ってください。別ネットワークから使う場合は Tailscale 行の URL を使います。

### AI アシスタントが表示されません

AI 機能はデスクトップ版のみで、Anthropic の API キーの設定が必要です。ブラウザ（外部アクセス）経由では表示されません。

### ショートカット一覧を見たい

アプリ内で `?` キーを押すとヘルプが開きます。[ショートカット一覧](/guide/shortcuts)にも同じ内容があります。
