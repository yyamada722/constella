# ガント

日程を横棒（バー）で見る表示です。ボードをまたいで、プロジェクト内のすべてのタスクが並びます。

![ガント表示](/media/tasks/gantt.png)

## 画面のなりたち

| 場所 | 内容 |
| --- | --- |
| 上部バー | 前後へ移動、**今日へ**、表示期間、ボードのフィルターチップ、ズーム、件数 |
| 左ペイン | タスク名のツリー。幅はドラッグで調整、折りたたみ可 |
| 右ペイン | 日付ヘッダー（月・日・曜日）とバー。週末と**日本の祝日**は背景色で区別 |
| 今日 | 青いピルと縦線 |

バー左端の細いストライプがボード色です。ボードのフィルターチップはクリックで単独表示 → 追加 / 解除、**`Alt`+クリック**でそのボードだけを隠せます。

## 期間をドラッグで変える

バーの中央をドラッグすると全体が移動、**右端 / 左端**をドラッグすると終了日 / 開始日が変わります。1 日単位でスナップします。

![バーのドラッグ](/media/tasks/gantt-drag.gif)

親タスクのバーは子から集計されるので、原則ドラッグできません。親に明示的な日付を付けた場合だけ動かせます。

## 日付未設定のタスク

日付のないタスクは、今日の位置に**破線のピル**で表示されます。クリックすると「今日 1 日」「今日 〜 +6 日」を一発で割り当てられ、ピルから右へ**ドラッグして期間を描く**こともできます。

![未設定タスクに日付を割り当てる](/media/tasks/gantt-undated.gif)

## バーをクリックして編集

バーをクリックすると、その場に編集ポップオーバーが開きます（内容は[タスクの追加と編集](./edit#編集ポップオーバー)と同じ）。

![ガント上の編集ポップオーバー](/media/tasks/gantt-editor.png)

## ズーム

| プリセット | 1 日の幅 | 表示期間 |
| --- | --- | --- |
| 標準 | 36px | 約 3 ヶ月（タスクに自動フィット ±14 日） |
| 3ヶ月 | 24px | 3 ヶ月 |
| 半年 | 10px | 半年（曜日表示は省略） |

![3ヶ月表示](/media/tasks/gantt-quarter.png)

## 遅延の表示

終了日を過ぎても完了していないタスクは、バーの右に**赤い破線の尻尾**と「+N d」が付きます。ダッシュボードの「遅延」バケットにも同じタスクが出ます。

## 左ペインでの並べ替え・親子化

左のタスク名をドラッグすると、行の上半分に落とせば**並べ替え**、下半分に落とせば**その行の子**になります（同じボード内のみ）。

## カレンダー表示

月のグリッドにタスクをステータス色で表示します。月のどこに予定が集中しているかを見るための表示で、編集はカンバンかガントで行います。

![カレンダー表示](/media/tasks/calendar.png)
