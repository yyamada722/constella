# タスクの全体像

タスクページは**ボード**ごとにタスクを持ち、同じデータを **カンバン / ガント / カレンダー** の 3 つの見方で扱います。

![カンバン表示](/media/tasks/kanban.png)

## ボード

左のパネルでボードを管理します。ボードは「撮影準備」「編集・納品」のような作業のまとまりです。

| 操作 | 方法 |
| --- | --- |
| 追加 | パネル上部の **＋** |
| 名前の変更 | ボード名を**ダブルクリック** |
| 色 | ボード行の色アイコン。ガントのバー左端のストライプとフィルターチップに使われる |
| 削除 | ボード行のゴミ箱 |
| 幅 | パネルの右端をドラッグ |

ボードの下にはタスク数が表示されます。

## ヘッダー

![ヘッダーの切り替え](/media/tasks/header.png)

| 項目 | 内容 |
| --- | --- |
| 階層 / フラット | カンバンで、サブタスクを親の下にまとめるか、すべて同列に並べるか |
| 検索 | タイトル・タグで絞り込み |
| 完了表示 / 完了非表示 | 完了タスクを隠す |
| 一括追加 | AI の出力やリストからまとめて登録（[タスクの追加と編集](./edit#一括追加)） |
| カンバン / ガント / カレンダー | 表示の切り替え |

## 3 つの表示

| 表示 | 向いていること | 詳しく |
| --- | --- | --- |
| カンバン | 今日の作業を進める。ステータスを動かす | [カンバン](./kanban) |
| ガント | 日程を組む。期間をドラッグで調整する | [ガント](./gantt) |
| カレンダー | 月の中でどこに予定が集中しているかを見る | [ガント](./gantt#カレンダー表示) |

## 親タスクと集計

タスクには**サブタスク**（子）を持たせられます。親のステータス・期間は子から自動で集計されます。

- 子がすべて完了すれば親も完了、ひとつでも進行中なら親は進行中
- 親の期間は子の最初から最後まで
- 親に自分の日付を明示的に付けることもでき、その場合は子が親の範囲を越えると警告が出ます

![親タスクの編集ポップオーバー（子からの集計）](/media/tasks/gantt-editor.png)

## ダッシュボードとの関係

全プロジェクトを横断した「遅延 / 今日 / 明日 / 近日」の一覧と、全プロジェクトのガントは**ダッシュボード**にあります。タスクページは「いまのプロジェクト」に集中する画面です。
