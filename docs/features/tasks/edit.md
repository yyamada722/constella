# タスクの追加と編集

## 追加する

各列の下の **＋ 追加** を押すとタイトル入力が現れ、`Enter` で確定します。列によって初期ステータスが決まります。

![タスクを追加](/media/tasks/add-task.gif)

親カードの「サブタスクを追加」からは、その親の子として直接作れます。

## 編集ポップオーバー

カードの鉛筆アイコン（またはガントのバーをクリック）で編集ポップオーバーが開きます。

![編集ポップオーバー](/media/tasks/edit-popover.png)

| 項目 | 内容 |
| --- | --- |
| タイトル・メモ | メモは Markdown 可 |
| 状態 | 親タスクでは「子から集計」と内訳（完了 / 進行中 / 未着手の件数）が表示される |
| 優先度 | P1〜P4 |
| 親 | どのタスクの子にするか（同じボード内） |
| 期間 | 開始日・終了日。片方だけなら 1 日の予定 |
| 他のプロジェクトのガントにも表示する | 共有（下記） |
| 関連ノート | ノートを検索して紐づけ。その場で新規作成も可 |
| ボード | 別のボードへ**移動 / 複製**（サブタスクごと） |

## 一括追加

ヘッダーの**一括追加**で、複数のタスクをまとめて登録できます。

![一括追加ダイアログ](/media/tasks/bulk-add.png)

- ダイアログには AI に依頼するための**プロンプト雛形**が用意されています。コピーして AI に渡し、返ってきた JSON を貼り付けるだけで階層付きで登録されます
- JSON でなくても、**インデント付きのリスト**（`- 親` の下に `  - 子`）を貼り付ければ階層として解釈されます
- 登録されたタスクには「AI 生成」のバッジが付きます

## 他のプロジェクトへの共有

「他のプロジェクトのガントにも表示する」をオンにすると、**代替タイトル**を入力する欄が出ます。他のプロジェクトのガントには、この代替タイトル（未入力なら「予定」）で**読み取り専用**のバーが表示されます。

案件名を出さずに「この期間は埋まっている」ことだけ他のプロジェクトに伝えられるので、複数案件の日程調整に使えます。

## 削除と取り消し

カードのメニューから削除します。削除したタスクは `Ctrl+Z` や画面下の「元に戻す」で復元できます。
