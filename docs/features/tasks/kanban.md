# カンバン

「未着手 / 進行中 / 完了」の 3 列にタスクカードが並びます。

## ステータスを変える

カードの左上の**ステータスピル**をクリックすると「未着手 → 進行中 → 完了 → 未着手…」と循環します。

![ステータスピルのクリック](/media/tasks/status-pill.gif)

クリック直後はすぐには列を移動せず、ピルの下に**カウントダウンバー**が出ます。約 2.6 秒のあいだに続けてクリックすれば選び直せ、止まった時点の状態で確定して列が移動します。「2 回押して完了」のような操作を、カードがその場から消えずに済ませるための仕組みです。

カードを別の列へ**ドラッグ**しても変えられます。

## カードの並べ替えとサブタスク化

カードのドラッグで同じ列内の並べ替えができます。**別のカードの下半分に重ねる**とそのカードの**サブタスク**になります。

![ドラッグでサブタスクにする](/media/tasks/nest-drag.gif)

親カードの下には子カードがインデントされて並び、「ここにドロップで子タスクとして追加」のゾーンに落としても同じことができます。親から外したいときは子カードのメニューから「親から外してルートに戻す」。

## 階層とフラット

| モード | 表示 |
| --- | --- |
| 階層 | 親カードの中に子を畳んで表示。列は親の集計ステータスで決まる |
| フラット | 親も子も同じ列に並べる。個々の子の状態で列が決まる |

![フラット表示](/media/tasks/kanban-flat.png)

## カードの情報

| 表示 | 意味 |
| --- | --- |
| P1〜P4 | 優先度（P1 が最優先） |
| 日付 | 開始日 〜 終了日。（明示）は親が自分の日付を持っている印 |
| ノートアイコン | 関連ノートあり。クリックで右側にノートパネルが開く |
| 進捗バー | 親タスクの子の完了割合（完了 / 進行中 / 未着手の 3 色） |
| AI 生成 | 一括追加で AI の出力から作られたタスク |

## 関連ノートパネル

タスクに関連ノートを付けておくと、カードを選んだときに右側へ**ノートパネル**が開き、タスクを見ながらノートを読み書きできます。複数のノートはタブで切り替え、パネル幅はドラッグで調整できます。

![関連ノートパネル](/media/tasks/note-panel.png)

## ショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す（ステータス変更・移動・削除も戻せる） |
| `Esc` | ポップオーバーを閉じる |
