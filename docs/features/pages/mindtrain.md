# 路線図

プロジェクトの工程を**路線図のように**描くページです。路線（ライン）に駅（マイルストーン）を並べ、進み具合を色と電車の位置で俯瞰します。ガントが「日付」で見る図なら、路線図は「流れと依存」で見る図です。

![路線図](/media/pages/mindtrain.png)

## 用語

| 要素 | 意味 |
| --- | --- |
| プラン | 1 枚の路線図。プロジェクトごとに複数持てる（ヘッダーの切替） |
| 路線 | 工程の流れ。名前と色を持つ |
| 駅 | マイルストーン / タスク。状態（計画中 / 建設中 / 開業）と形を持つ |
| 乗換駅 | 2 つ以上の路線が通る駅。複数の流れが合流する地点 |
| 電車 | 路線上を走るマーカー。進捗（開業した駅の範囲）に応じて位置が動く |

## 駅を置く

1. 左の「路線」で路線を追加し、選択します
2. 下部の **駅を配置**（または `A` キー）で配置モードに入り、キャンバスをクリックして駅を置きます。`Esc` で終了
3. 別の路線を選んで既存の駅をクリックすると、その駅が**乗換駅**になります

駅はドラッグで移動、空白ドラッグで範囲選択、`Shift`+クリックで複数選択、`Delete` で削除です。

## 駅の詳細

駅をクリックすると右に詳細パネルが開きます。

![駅の詳細](/media/pages/mindtrain-station.png)

| 項目 | 内容 |
| --- | --- |
| 駅名 / 状態 | 計画中 → 建設中 → 開業 |
| シェイプ | 角丸四角 / 円 / 四角 / ひし形 / 六角形 / 三角形 |
| 色 | 既定は路線色（乗換駅は墨色） |
| 所属路線 | 外すと路線から切り離される |
| 関連カード | キャンバスのカードと相互リンク。駅 ↔ カードを行き来できる |
| メモ / リンク | 目的・参考 URL |

駅の周りに出る 8 方向の矢印で、駅名ラベルの位置を変えられます。

## 路線と電車

左の路線をクリックすると路線パネルが開き、名前・色の変更、駅の並び、**電車**の追加ができます。電車は始点と終点の駅を指定し（「キャンバスで駅を選択」）、形は 4 種類。開業した駅の範囲に合わせて自動で進みます。

## 注釈

ツールバーから**エリア**（背景の矩形。フェーズ分けに）、**テキストラベル**、**画像**を置けます。

## 他のページとの連携

- キャンバスの「路線図」カードで、このプランをキャンバス上にライブ表示
- 横断検索の対象に「駅」が含まれる

## ショートカット

| キー | 動作 |
| --- | --- |
| `A` | 駅の配置モード（`Esc` で終了） |
| `Delete` / `Backspace` | 選択した駅・注釈を削除 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 元に戻す / やり直す |
| 中ボタンドラッグ | パン |
