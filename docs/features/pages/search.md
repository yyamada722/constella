# 検索

いまのプロジェクトの中を横断して検索します。

![検索](/media/pages/search.gif)

対象は **ノート / タスク / リサーチ / キャンバスのカード / ラベル / 駅** の 6 種類。ヒットした箇所はハイライトされ、結果をクリックするとそのページの該当箇所（ノートならそのノート、カードならキャンバスのそのカード）へジャンプします。

![検索結果](/media/pages/search.png)

- 検索語の履歴は入力欄のドロップダウンに残ります
- ノート一覧・リサーチ一覧・キャンバスにはそれぞれページ内の検索もあります。「どこに書いたか分からない」ときはこのページ、場所が分かっているときはページ内検索、と使い分けてください
