# ダッシュボード

プロジェクトを**横断して**タスクの状況を一望する画面です。ほかのページが「いま選んでいるプロジェクト」を扱うのに対し、ここだけはアーカイブ以外のすべてのプロジェクトを対象にします。

## やること

![やること](/media/pages/dashboard-agenda.png)

全タスクを期限で仕分けます。

| バケット | 条件 |
| --- | --- |
| 遅延 | 終了日を過ぎているのに未完了（超過日数付き） |
| 今日 / 明日 | 終了日が今日 / 明日 |
| 近日 | 今日から約 1 週間以内 |

行にはプロジェクト名とボード名が付き、クリックするとそのタスクへ移動します。上部のチップで 1 バケットだけに絞れます。

ヘッダーの**ベル**には遅延と今日の件数が常に表示され、どのページにいてもクリックで「やること」に来られます。

## ガント

![全プロジェクトのガント](/media/pages/dashboard-gantt.png)

全プロジェクトのタスクを 1 枚のガントに並べます。操作はタスクページのガントと同じで、プロジェクトごとにグループ化されます。他プロジェクトへの共有タスクもここで重なりを確認できます。

## プロジェクト別

![プロジェクト別](/media/pages/dashboard-summary.png)

プロジェクトごとに「未着手 / 進行中 / 完了 / 日付未設定」の件数と進捗を表示します。並び順は「要対応順（遅延・今週・未設定が多い順）」と「作成順」から選べ、**絞り込み**でプロジェクトを限定できます。プロジェクトが多いときは、サイドバーのプロジェクト切替にある検索とピン留めと合わせて使ってください。
