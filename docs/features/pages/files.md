# ファイル

写真・PDF・動画・音声などを**プロジェクトのライブラリ**として一か所で管理するページです。ノートの付随資料、タスクの資料リンク、キャンバスのカードは、すべてここにあるファイルへの**参照**になります。「同じ PDF をノートにもタスクにも貼ったら 2 重に保存された」「差し替えたのに古いほうが残っている」を防ぐ仕組みです。

![ファイル（グリッド表示）](/media/pages/files-grid.png)

## 登録する

| 方法 | 内容 |
| --- | --- |
| ＋ 追加 | ファイルを選んでアプリに取り込む。原本のバイト列をそのまま保存 |
| ドラッグ＆ドロップ | 一覧にファイルを落とす |
| サーバー参照 | NAS などのファイルを**取り込まずパスだけ**登録（大容量動画向け）。アイコンにリンクマークが付く |
| 他のページから | ノートの付随資料・タスクの資料リンク・キャンバスへのドロップで追加したファイルも自動でここに入る |

## 整理する

- **フォルダー**（入れ子・色）、**タグ**、**コメント**（「先方からの MTG 資料」など）。コメントは横断検索の対象
- 左レールの **未分類 / 未使用** で、フォルダー未設定のファイルや、どこからも参照されていないファイルを拾える（掃除用）
- 上部の種類フィルター（画像 / 動画 / PDF / 音声 / その他）、並び順、グリッド / リスト切替

![リスト表示](/media/pages/files-list.png)

## 見る

ファイルをクリックするとプレビューが開きます。

![プレビューと詳細](/media/pages/files-detail.png)

| 種類 | プレビュー |
| --- | --- |
| 画像 | ズーム（`Ctrl`+ホイール / ピンチ）、ドラッグでパン、ダブルクリックでリセット |
| PDF | ページ送り・スクロール・見開き、ズーム（0.5〜8 倍）、`PageUp` / `PageDown` / `Home` / `End`、全画面 |
| 動画 | 再生 |
| 音声 | 波形付きプレイヤー |

`←` / `→` で前後のファイルに移動できます。右の詳細では名前・コメント・タグ・フォルダーを編集し、**他プロジェクトに表示**（参照として共有）を切り替えられます。

## 使用先

詳細の「使用先」に、このファイルを使っているノート・タスク・キャンバスカードが並びます。クリックでそこへジャンプします（他プロジェクトならプロジェクトを切り替えてから）。「ノートに添付」「タスクにリンク」からその場で紐づけることもできます。

## 版の差し替え

「**新しい版に差し替え**」で新しいファイルをアップロードすると、ノート・タスク・カードからの参照はそのまま新しい版を指し、旧版は**履歴**に残ります。履歴から「この版を現行に戻す」も可能です。修正版の PDF を受け取ったときに、貼り直して回る必要がありません。

## 削除

「ライブラリから削除」は実体を消します。使用先があるときは確認が出ます。他プロジェクトからの参照を外すだけなら、その参照側で「このプロジェクトでの表示をやめる」を使ってください（所有プロジェクトのファイルは残ります）。
