# リサーチ

内蔵ブラウザで調べ物をし、見つけたページをブックマークとして整理するページです。

![リサーチ](/media/pages/research.png)

## ブラウザ

| 操作 | 方法 |
| --- | --- |
| 開く | URL バーに入力して「移動」。検索語を入れれば Google 検索 |
| 戻る / 進む / 再読み込み / ホーム | ツールバー左のボタン |
| このページを保存 | 表示中のページをブックマークに登録 |
| 外部ブラウザで開く | 右端のアイコン（ログインが必要なサイトなどに） |

一部のサイトは埋め込み表示を拒否します。その場合は外部ブラウザで開いてください。

## ブックマーク

左の一覧に保存したページが並びます。

- **フォルダー**（入れ子・色）で整理、ドラッグで移動
- **タグ**と説明文を付けられ、一覧上部の検索で絞り込み
- 使い終わったものは**アーカイブ**（「アーカイブ」で表示・復元）
- **JSON で書き出し**して別のプロジェクトや PC へ持ち出せる

ブックマークの内容は横断検索の対象になり、キャンバスの「リサーチ」カードとしても配置できます。
