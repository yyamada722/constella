# スケッチ

手書き専用のホワイトボードです。絵コンテ、構図のラフ、打ち合わせ中の走り書きに。

![スケッチ](/media/pages/sketch.png)

## 描く

![ペンで描く](/media/pages/sketch-pen.gif)

| ツール | 内容 |
| --- | --- |
| ペン | 8 色 × 4 段階の太さ |
| 消しゴム | **なぞった部分だけ消す** / **触れた線を丸ごと消す** の 2 方式 |
| 全消去 | シート全体を消す（`Ctrl+Z` で戻せる） |

ホイールでズーム、ドラッグでパン、`Ctrl+0` または「全体表示」で全体を表示します。

## 書き出し

- **PNG** — ラスター画像
- **SVG** — ベクター。線が滑らかなまま他のツールで使える

## キャンバスで使う

描いたスケッチは、キャンバスに「**スケッチ**」カードとして配置できます。カードはスケッチの内容を読み取り専用でライブ表示し、スケッチ側を直すとカードも更新されます。カードの「スケッチで開く」からこのページへ戻れます。

## ショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Ctrl+0` | 表示をリセット |
