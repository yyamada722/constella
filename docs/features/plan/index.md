# 計画（旅程）の全体像

出張・ロケハン・イベントの行程を**テキストで**組むページです。左に Markdown、右にそれを解釈した時系列のタイムライン。費用は自動で集計され、e チケットの PDF を添付して 1 冊の PDF にまとめられます。

![計画ページ（分割表示）](/media/plan/overview.png)

## なぜテキストなのか

予定は往々にして直前まで動きます。フォーム入力よりテキストの方が「行を 1 本足す」「時刻だけ直す」「2 日目を丸ごと入れ替える」が速く、コピーして別案を作るのも簡単です。記法は TripMD 互換のごく小さなものなので、数行書けば覚えられます。

```md
## 2026-08-18

> [07:30] flight JAL503 from 羽田^HND to 新千歳^CTS
> - price: JPY {28000*2}
> [13:00] - [15:00] location 大通公園 ロケハン at 大通公園
> [18:00] hotel チェックイン :: 札幌グランドホテル
```

## タイムライン

![タイムライン表示](/media/plan/timeline.png)

- 日付ごとに区切られ、ヘッダーに**期間・日数・予定件数・費用の合計**
- 予定は種別ごとのアイコンと色。移動は「出発地 → 到着地」、略号（`^HND`）はバッジ
- `price` を書いた予定には金額チップ。通貨が混ざっても通貨別に合計
- 場所を書いた予定には**地図**チップ（クリックで地図を開く）
- `[!NOTE]` などのアラートは色付きボックス

## 画面の操作

![ツールバー](/media/plan/toolbar.png)

| ボタン | 内容 |
| --- | --- |
| 添付 | PDF・画像をアプリに取り込み、`[名前](idb:…)` リンクをカーソル位置に挿入 |
| サーバー参照 | NAS などのファイルを取り込まず、`[名前](local:パス)` として挿入 |
| ? | 記法ヘルプ（下記） |
| PDF | この計画を PDF に書き出し |
| 編集 / 分割 / プレビュー | 表示モード |

![記法ヘルプ](/media/plan/syntax-help.png)

記法の完全な説明は [計画（旅程）記法リファレンス](/reference/plan-syntax) にあります。

分割表示なら、行を足したそばからタイムラインに反映されます。

## 計画の整理

![計画の一覧](/media/plan/sidebar.png)

| 操作 | 方法 |
| --- | --- |
| 新しい計画 | 上部の **＋**。テンプレートが入った状態で作られる |
| フォルダー | ノートと同じ操作感（入れ子・色・ドラッグで移動） |
| 複製 | 行のメニューから。「v2」「v3」と版が採番されるので案の比較に |
| 名前の変更 | 計画名をクリック |

## PDF 書き出し

**PDF** ボタンで「本文 → 目次 → 別紙」の順に 1 冊の PDF を作ります。添付した PDF・画像は別紙ページとして末尾に結合され、目次からリンクでジャンプできます。同行者にそのまま配れる形です。

## リンクと添付をその場で開く

プレビューの中で `[名前](URL)` や添付のリンクをクリックすると、その場に内容がインライン展開されます。e チケットの PDF を予定行にぶら下げておけば、当日はタイムラインから直接開けます。
