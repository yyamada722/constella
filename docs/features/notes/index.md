# ノートの全体像

Markdown で書くメモ・議事録・ドキュメントのページです。左にノート一覧、右にエディタとプレビュー。書いたそばから整形され、PDF・スライド・Markdown ファイルに書き出せます。

![ノートの全体像（分割表示）](/media/notes/overview.png)

## 一覧とフォルダー

![ノート一覧](/media/notes/sidebar.png)

| 操作 | 方法 |
| --- | --- |
| ノートを追加 | 上部の **＋**。選択中のフォルダーの中に作られる |
| フォルダーを追加 | フォルダー＋アイコン。フォルダー行のメニューから**サブフォルダー**も作れる |
| フォルダーの開閉 | 行左のシェブロン |
| フォルダー名の変更・色 | フォルダー名をクリックで名前編集、色アイコンで色を変更 |
| ノートをフォルダーへ | ノートを**ドラッグ**してフォルダー行へ |
| ピン留め | ノート右上の★。ピン留めしたノートは一覧の先頭に固定 |
| 並び順 | 「更新順 / 作成順 / タイトル順」 |
| 検索 | 一覧上部の検索ボックス（タイトル・本文・タグを対象） |
| アーカイブ | 使い終わったノートはアーカイブへ。一覧から消えるが「アーカイブを表示」で戻せる |

一覧の各ノートには本文の冒頭とタグが表示されるので、開かなくても中身の見当が付きます。

## 表示モード

![編集 / 分割 / プレビュー と文字サイズ](/media/notes/mode-toggle.png)

| モード | 使いどころ |
| --- | --- |
| 編集 | ソースだけを広く使いたいとき |
| 分割 | 左にソース、右にプレビュー。書きながら確認する通常モード |
| プレビュー | 読むとき・人に見せるとき。チェックボックスはこの画面でクリックして切り替え可 |

![プレビューモード](/media/notes/preview-mode.png)

文字サイズは **−** / **＋** で 75〜200% の範囲で調整できます（編集・プレビューの両方に効きます）。

## タグとバックリンク

タイトルの下にタグを付けられます。タグは一覧の検索対象になります。

「バックリンク」の行には、このノートにリンクしている他のノート・タスク・キャンバスカードが並びます。タスクの「関連ノート」に登録したり、キャンバスの wiki リンクで参照したりすると、ここから辿り返せます。
