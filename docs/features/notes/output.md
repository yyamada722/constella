# 読み込み・書き出し・スライド・共有

## 読み込み

一覧上部の**読み込み**ボタンから、外部のテキストファイル（.md / .txt）をノートとして取り込めます。複数選択でまとめて取り込め、その場合も `Ctrl+Z` 一回で全部戻せます。

- Markdown の先頭見出し（`# タイトル`）はノートのタイトルに昇格します
- Constella 自身が書き出した .md の frontmatter（タイトル・タグ）はそのまま復元されます（往復可能）
- プレーンな .txt はファイル名がタイトルになります

## 書き出し

ヘッダー右のアイコンから:

| 形式 | 内容 |
| --- | --- |
| Markdown (.md) | ソースをそのままファイルに |
| PDF | A4 の文書レイアウト。見出し・表・コード・図もそのまま |

## スライドショー

本文を `---`（水平線）で区切っておくと、**スライドショー**ボタンで 16:9 のスライドとして全画面再生できます。打ち合わせでノートをそのまま投影したいときに便利です。

![スライドショー](/media/notes/slideshow.png)

![矢印キーでスライド送り](/media/notes/slideshow-nav.gif)

| キー | 動作 |
| --- | --- |
| `→` `Space` `PageDown` | 次へ（画面右側クリックでも） |
| `←` `PageUp` | 前へ（画面左側クリックでも） |
| `Home` / `End` | 最初 / 最後へ |
| `Esc` | 終了 |

右上のボタンから、同じスライドを 16:9 の **PDF** に書き出すこともできます。

## 付随資料（添付）

ヘッダーの **📎** ボタンで付随資料パネルが開きます。PDF・画像・動画・音声を「追加」（またはドロップ）で添付するか、「ライブラリから」で**ファイル**ページに登録済みのものを選びます。

![付随資料パネル](/media/notes/attachments.png)

- **グループ**（先方 / 自分 など）で仕分けできます
- 添付の実体は[ファイルライブラリ](/features/pages/files)に保存され、ノートからは参照です。同じファイルをタスクやキャンバスでも使え、版を差し替えれば全部に反映されます
- クリックでその場にプレビュー（PDF・画像はズーム可）。「ファイルライブラリで表示」で詳細へ
- 一覧のノート名の横に 📎 と件数が表示されます

NAS など上のファイルを取り込まずに参照だけしたい場合は、本文に `[名前](local:パス)` の形で書くと、クリックで OS の既定アプリで開けます（[Markdown 記法リファレンス](/reference/markdown#添付ファイルとローカル参照)）。

## 他プロジェクトとの共有

![共有ノート](/media/notes/shared-note.png)

ヘッダーの**共有**アイコンをオンにすると、このノートは他のプロジェクトから参照できる「マスター」になります。

1. 共有したいノートで共有をオンにする
2. 別のプロジェクトに切り替え、ノート一覧の「他プロジェクトの共有ノートを参照に追加」から選ぶ
3. 参照先では「参照」バッジ付きで表示される。内容はひとつなので、どちらで編集しても同じノートが更新される

連絡先一覧や共通のルールなど、プロジェクトをまたいで使う資料に向いています。参照を外しても元のノートは消えません。

## 新しいノートを作る

**＋** を押すとタイトル入力状態の新しいノートが作られます。

![ノートを追加](/media/notes/new-note.gif)

## 削除と復元

ヘッダーのアーカイブアイコンで一覧から退避（復元可能）、ゴミ箱で完全削除です。完全削除も直後なら `Ctrl+Z` や画面下の「元に戻す」で戻せます。
