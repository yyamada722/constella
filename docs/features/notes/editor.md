# エディタの使い方

## ツールバー

![エディタのツールバー](/media/notes/editor-toolbar.png)

左から: 太字 / 斜体 / 取り消し線 / インラインコード / 見出し 1〜3 / 引用 / 箇条書き / 番号付き / チェックリスト / リンク / 画像 / 表 / コードブロック / 水平線。

テキストを選択してから押すとその範囲に記法が付き、選択していなければその場に記法が挿入されます。

## 書きながら整形される

分割表示にしておくと、入力した内容がすぐ右に反映されます。

![入力と同時にプレビューが更新される](/media/notes/typing.gif)

エディタには「スマート Enter」が入っています。

- リストや引用の行で `Enter` → 同じ記号が次の行に自動で付く（番号付きリストは番号が増える）
- 何も書かずにもう一度 `Enter` → リストを抜ける
- `Tab` / `Shift+Tab` → リストのインデント / アウトデント
- 表の中では `Tab` で次のセル、行末の `Tab` で行追加

## 右クリックの挿入メニュー

編集中に右クリックすると「記法を挿入」メニューが開きます。ツールバーより多くの部品が揃っています。

![右クリックでコールアウトを挿入](/media/notes/insert-menu.gif)

| グループ | 項目 |
| --- | --- |
| 文字 | 見出し 1〜3、太字、斜体、取り消し線、インラインコード、ハイライト |
| リスト | 箇条書き、番号付き、チェックリスト、引用 |
| リンク | リンク、画像 (URL)、画像ファイル、参照リンク、脚注 |
| ブロック | コードブロック、Mermaid 図、数式ブロック、表、コールアウト、水平線 |
| 挿入 | 今日の日付、現在日時、議事録テンプレート、日報テンプレート |

記法そのものの一覧は [Markdown 記法リファレンス](/reference/markdown) にまとめています。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+B` / `Ctrl+I` | 太字 / 斜体 |
| `Ctrl+E` | インラインコード |
| `Ctrl+K` | リンク |
| `Ctrl+Shift+X` | 取り消し線 |
| `Ctrl+F` / `Ctrl+H` | ノート内検索 / 置換 |
| `Ctrl+Shift+E` | 編集 ⇔ プレビューを切り替え（スクロール位置を維持） |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |

## 貼り付け

| 貼り付けるもの | 結果 |
| --- | --- |
| 画像（スクリーンショットなど） | そのまま画像として挿入。実体はアプリ内に保存 |
| URL（テキストを選択した状態で） | 選択部分がそのリンクになる |
| Web ページの一部 / Word / Excel の表 | 見出し・リスト・表などが Markdown に変換される |
| `Ctrl+Shift+V` | 変換せずプレーンテキストで貼り付け |

## 検索と置換

`Ctrl+F` で検索バーが開き、ヒット件数と現在位置が表示されます。`Enter` で次へ、`Shift+Enter` で前へ。

![ノート内検索](/media/notes/find.gif)

`Ctrl+H` で置換欄が加わり、「1 件置換」「すべて置換」ができます。`Esc` で閉じます。

## アウトラインとミニマップ

アウトラインは見出しの目次です。長いノートで目的の節に飛ぶときに使います。

![アウトライン](/media/notes/outline.png)

右端の**ミニマップ**はノート全体の縮図で、いま見ている範囲が強調されます。クリックやドラッグでその位置へ移動できます。分割表示では左右のスクロールが同期します。

![ミニマップ](/media/notes/minimap.png)
