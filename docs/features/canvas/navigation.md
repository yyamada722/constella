# 移動・ズーム・表示

## パンとズーム

| 操作 | 方法 |
| --- | --- |
| ズーム | マウスホイール（カーソル位置を中心に拡大縮小）、ツールバーの − / ＋、またはピンチ |
| パン（画面を動かす） | `Space` を押しながらドラッグ、または中ボタンドラッグ |
| 全体表示 | ツールバーの全体表示ボタン（すべてのカードが収まる倍率に） |
| 倍率のリセット | 倍率の数字をクリック |

![パンとズーム](/media/canvas/pan-zoom.gif)

ズームの速さは、倍率の数字をクリックするか、設定メニューの「ズーム感度」で調整できます（トラックパッドで速すぎると感じたときに）。

## ミニマップ

ツールバーの**ミニマップ**ボタンで右下に全体図を表示します。現在見えている範囲が枠で示され、ミニマップ上をクリック / ドラッグするとその場所へ移動できます。

![ミニマップ](/media/canvas/minimap.png)

## グリッドスナップ

オンにすると、カードの移動・サイズ変更が 20px 単位に揃います。背景のドットがそのグリッドです。構成図をきれいに揃えたいときに。

## リスト表示

ツールバーの**リスト**ボタンで、タブ内のカードを一覧表示に切り替えます。位置に関係なくカードの内容を上から順に読めるので、テキストカードが多いタブの確認に向いています。

![リスト表示](/media/canvas/list-view.png)

## 編集ロック

ツールバーの鍵アイコンで**編集ロック**をオンにすると、カードの移動・編集・削除ができなくなります（閲覧のみ）。完成した図を人に見せるときや、誤操作を防ぎたいときに使います。カード単位のロックはプロパティパネルから。

## キャンバス内検索

虫眼鏡アイコンから、このタブにあるカードのタイトル・本文を検索できます。ヒットしたカードへジャンプします。すべてのタブを横断して探したいときはサイドバーの「検索」ページを使ってください。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| ホイール | ズーム |
| `Space`+ドラッグ / 中ボタン | パン |
| `Ctrl+A` | 全選択 |
| 矢印キー（`+Shift`） | 選択カードを移動（大きく移動） |
| `Esc` | 選択解除・ツールを「選択」に戻す |

すべての一覧は [ショートカット](/guide/shortcuts) を参照してください。
