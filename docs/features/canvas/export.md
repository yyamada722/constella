# 書き出しと共有

ツールバー右側の書き出しボタンから、現在のタブを 3 つの形式で書き出せます。

| 形式 | 用途 |
| --- | --- |
| PNG | いま表示している範囲を画像として保存。資料に貼る、チャットで送る |
| 共有用 HTML | **アプリを持っていない相手**に渡す。ブラウザで開くだけで閲覧・パン / ズーム・動画再生ができる |
| JSON | タブのデータをそのまま書き出す（バックアップ・別プロジェクトへの移植） |

## 共有用 HTML

![共有用 HTML の書き出し](/media/canvas/export-share.png)

1 枚の HTML ファイルにカード・矢印・手書き・画像・動画までまとめて書き出します。受け取った人はブラウザで開くだけで、アプリと同じようにパン / ズームして閲覧できます。

### 動画・音声の埋め込み上限

動画や音声は HTML に直接埋め込むとファイルが大きくなるため、上限を選べます。

| 設定 | 動作 |
| --- | --- |
| 50MB / 150MB / 300MB / 500MB | 合計がこの範囲に収まる分だけ埋め込む |
| 無制限 | すべて埋め込む |
| 埋め込まない | 動画・音声は埋め込まず、サムネイル付きリンクとして書き出す |

ダイアログにはメディアの件数と**書き出し後のおおよその容量**が表示されるので、送る手段に合わせて選んでください。「上限を超えた動画を縮小して埋め込む」をオンにすると、大きい動画を 720p の WebM に再エンコードして収めます（動画の長さに応じて時間がかかります）。

YouTube や Web ページのカードは、サムネイル付きのリンクとして書き出されます。

## PNG

いま画面に見えている範囲を、そのままの倍率で画像にします。全体を入れたいときは先に**全体表示**を押してから書き出してください。

## JSON

現在のタブのカード・矢印・グループなどを JSON で保存します。アプリ全体のバックアップは設定メニューの「バックアップを書き出し」を使ってください（[データとバックアップ](/guide/data)）。

## 他のページから参照する

書き出さなくても、キャンバスの内容は次の方法でアプリ内から参照できます。

- ノートの本文で `[[` カードタイトル `]]` と書くと、そのカードへジャンプするリンクになります
- 別のタブに**キャンバスリンク**カードを置くと、プレビュー付きのショートカットになります
- 路線図ページの駅とカードは相互にリンクできます
