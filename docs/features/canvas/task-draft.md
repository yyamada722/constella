# タスク下書きからタスクへ

「まず付箋のように思いつくまま並べ、つないで、最後にまとめてタスクにする」ための仕組みです。タスクページで 1 つずつ登録するより、段取りを考えながら作れます。

![タスク下書きカード](/media/canvas/task-draft.png)

## 下書きカードを置く

- ツールバーの**タスク下書き**ツールを選び、キャンバスをクリックすると、その位置に下書きカードが置かれます。ツールは選ばれたままなので、連続クリックでどんどん並べられます（`Esc` で終了）
- 右クリックメニューの「タスク下書き」からも 1 枚ずつ置けます

黄色の破線で囲まれたカードが下書きです。タイトルと「大体いつ」を書き込みます。

## キーボードで連鎖させる

下書きカードを選択した状態で:

| キー | 動作 |
| --- | --- |
| `Tab` | 右に**子**の下書きを作り、矢印（親 → 子）でつなぐ |
| `Enter` | 下に**兄弟**の下書きを作る（同じ親につながる） |

![Tab / Enter で連鎖](/media/canvas/task-draft-chain.gif)

新しいカードはすぐタイトル入力になるので、`Tab`・`Enter` を押しながら打ち込むだけでツリーが組み上がります。

## 親子関係は矢印で決まる

下書きカード同士を**矢印**でつなぐと「親 → 子」です。タスク化のとき、子は親の**サブタスク**として登録されます。`Tab` で作ったカードにはこの矢印が自動で付いています。

## 「大体いつ」チップ

カードの **月頭 / 初旬 / 中旬 / 下旬 / 月末** チップで、時期の目安を付けられます。タスク化のときに具体的な日付（今月、すでに過ぎていれば来月）の終了日に変換されます。日付は未定のままでも構いません。

## タスク化する

ツールバーの **タスク化 N** ボタン（N は未変換の下書き枚数）を押すと、追加先のボードを選ぶダイアログが開きます。既存のボードを選ぶか、新しいボードを作って、タブ内の下書きをまとめて実タスクに変換します。

- 変換後、カードは **TODO カード**（実タスクと連動）に変わります。以降はカード上でステータスを変えると元のタスクに反映されます
- 変換は 1 回の操作として記録されるので、`Ctrl+Z` で丸ごと戻せます

::: tip フローページとの違い
同じ「下書き → タスク化」は**フロー**ページでもできます。フローはノードの接続と月指定に特化した専用画面、キャンバスは資料や図と一緒に段取りを考えたいときに向いています。
:::
