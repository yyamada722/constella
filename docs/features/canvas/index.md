# キャンバスの全体像

キャンバスは、カード・矢印・手書き・図形を自由に置ける無限に広がるボードです。企画の発散、資料の集約、構成図、工程の下書きまで、ひとつの場所で扱えます。

![キャンバスの全体像](/media/canvas/overview.png)

画面は左から **ボードパネル**（タブの切り替え）、**ツールバー**＋**キャンバス本体**、右の **プロパティパネル**（選択中の要素の設定）で構成されます。

## ボードとタブ

キャンバスは「**ボード** → **タブ**」の 2 段階で整理します。ボードは大分類（例: 企画、機材・システム）、タブはその中の 1 枚のキャンバスです。

![ボードパネル](/media/canvas/boards-panel.png)

| 操作 | 方法 |
| --- | --- |
| ボードを追加 | パネル上部のフォルダー＋アイコン |
| タブを追加 | ＋アイコン（選択中のボードの下に作成） |
| 名前の変更 | ボード名 / タブ名を**ダブルクリック** |
| ボードの色 | ボード名の左の●をクリック |
| タブを別ボードへ | タブ名を**ドラッグ**して移動 |
| 削除 | ボード行の右端のゴミ箱（中のタブは「未分類」へ） |

タブ名の右の数字は、そのタブにあるカードの枚数です。パネルは左上のアイコンで折りたためます（折りたたみ中はマウスを乗せると一時的に開きます）。

## ツールバー

![ツールバー](/media/canvas/toolbar.png)

左から順に:

| 位置 | 内容 |
| --- | --- |
| ＋ | カードを追加（メニューからカード種別・図形を選ぶ） |
| ツール 8 種 | 選択 / 矢印 / グループ / ペン / 消しゴム / ラベル / タスク下書き / 線路（[ツール](./tools)） |
| 取り消し / やり直し | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 表示 | キャンバス / リスト切替、編集ロック、グリッドスナップ、ミニマップ |
| ズーム | − / 倍率 / ＋ / 全体表示 |
| 書き出し | PNG、共有用 HTML、JSON、キャンバス内検索（[書き出し](./export)） |

カードや矢印を選択すると、ツールバーに整列・色・前面 / 背面などの**選択中だけ使えるボタン**が追加されます。ウィンドウが狭いときはツールバーが 2 段に折り返されます。

## プロパティパネル

右側のパネルには、何も選んでいないときはタブの概要（カード数・路線数・駅数）、カードを選ぶとそのカードのタイトル・色・位置・ロック・削除が表示されます。

![プロパティパネル](/media/canvas/props-panel.png)

矢印を選ぶとラベル・曲線 / 直線・色・太さ、線路を扱っているときは路線と駅の編集 UI がここに出ます。パネルは右上のアイコンで折りたためます。
