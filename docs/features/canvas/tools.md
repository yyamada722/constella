# ツール

ツールバー左側の 8 つのボタンで「いま何をするか」を持ち替えます。`Esc` でいつでも**選択**ツールに戻ります。

| ツール | 用途 |
| --- | --- |
| 選択 / 移動 | 通常の操作。クリックで選択、ドラッグで移動、背景ドラッグで範囲選択 |
| 矢印 | カードからカードへ矢印を引く |
| グループ | ドラッグで枠を描き、中のカードをまとめる |
| ペン | 手書き |
| 消しゴム | 手書きを消す（部分 / 線ごと） |
| ラベル | キャンバスに直接テキストを置く |
| タスク下書き | クリックした場所に下書きカードを連続配置 |
| 線路 | 路線図を描く（駅を連続配置） |

## 矢印

**矢印**ツールを選び、元のカードから先のカードへドラッグします。カードの輪郭に吸着し、カードを動かしても追従します。

![矢印を引く](/media/canvas/arrow.gif)

- ドラッグ中はカードの **8 方向ポート**（上下左右＋四隅）が表示され、近づけるとそこに固定できます。固定しない場合はカードの中心同士を結ぶ最短位置に自動で付きます
- 矢印を選択して、右のプロパティパネルで**ラベル・曲線 / 直線・色・太さ**を変更できます
- 矢印を選択すると線の中間に薄いハンドルが出ます。それをドラッグすると**折れ点**が追加され、経路を曲げられます（折れ点はダブルクリックで削除、右クリックメニューで一括削除）
- 空いている場所から引き始めると、カードに接続しない自由な矢印になります
- 矢印は範囲選択・`Shift`+クリック・`Ctrl+A` でカードと一緒に複数選択でき、まとめて移動・複製・削除できます（自由端や折れ点も一緒に動きます）

::: tip タスク下書きの親子関係
タスク下書きカード同士を矢印でつなぐと「親 → 子」の関係になり、タスク化したときにサブタスクとして登録されます。→ [タスク下書きからタスクへ](./task-draft)
:::

## グループ

**グループ**ツールで範囲をドラッグすると、枠が作られます。枠の中のカードは枠ごと移動できます。

![グループ化](/media/canvas/group.gif)

- カードを選択して `Ctrl+G` でも、選択範囲を囲むグループを作れます。`Ctrl+Shift+G` で解除
- グループは入れ子にできます
- 枠のタイトルをクリックして名前を変更。枠だけ削除してもカードは残ります

## ペンと消しゴム

**ペン**はフリーハンドで書き込めます。色と太さはツールバーで選びます。

![手書き](/media/canvas/pen.gif)

**消しゴム**は 2 方式:

| 方式 | 動作 |
| --- | --- |
| 部分消し（ブラシ） | なぞった部分だけ消える。ブラシの大きさを調整可能 |
| ストロークごと削除 | 触れた線を丸ごと消す |

## ラベル

**ラベル**ツールでキャンバスをクリックすると、その場所にテキストを置けます。文字サイズと色を変えられ、見出しや注釈に便利です。

## シェイプ（図形）

右クリックメニューの「シェイプを追加」から、構成図用の図形を置けます。

![シェイプ図形のメニュー](/media/canvas/shape-menu.png)

四角形 / 角丸四角 / 円・楕円 / ひし形 / 三角形 / 平行四辺形 / 六角形 / 円柱(DB) / クラウド / ファイル / フォルダー / 人 / PC / サーバー の 14 種類。ヘッダーのない図形カードで、ラベル（タイトル）が図形の中に表示されます。矢印は図形の輪郭に吸着するので、システム構成図やフローチャートがそのまま描けます。

![シェイプで描いた構成図](/media/canvas/shapes.png)

## 線路（路線図）

**線路**ツールを選ぶと、クリックした場所に**駅**が置かれ、連続クリックで路線が延びていきます。既存の駅をクリックするとそこから延伸でき、2 つ以上の路線が通る駅は**乗換駅**として表示されます。

![線路で描いた進行ロードマップ](/media/canvas/rails.png)

- 駅には **計画中 / 建設中 / 開業** の状態を付けられ、色で進み具合がわかります
- 路線の名前と色、駅の名前・状態・所属路線は右のプロパティパネルで編集します
- 駅はドラッグで移動でき、路線は追従します

路線図ページで描いた本格的な路線図を埋め込みたい場合は、「路線図」カードを使ってください。
