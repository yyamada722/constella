# カードの種類と操作

## カードを追加する

キャンバスの空いている場所を**右クリック**するとメニューが開き、その位置にカードを置けます。ツールバーの **＋** ボタンからも同じメニューが開きます（その場合は画面中央に配置）。

![右クリックメニュー](/media/canvas/context-menu.png)

![カードを追加](/media/canvas/add-card.gif)

画像・PDF・動画・音声はファイルを**キャンバスにドラッグ＆ドロップ**するか、クリップボードから **貼り付け（Ctrl+V）** しても配置できます。配置したファイルは[ファイルライブラリ](/features/pages/files)に登録され、ライブラリ側で版を差し替えるとカードも追随します。

## カードの種類

| カード | 用途 |
| --- | --- |
| テキスト | Markdown で書ける本文カード。複数ページを持てる |
| メモ | 短いメモ。**ノート**と連動させると実際のノートを表示・編集できる |
| TODO | 実際の**タスク**と連動。ステータスや期間をカード上で変更すると元のタスクに反映 |
| リサーチ | 調べ物の要点＋URL |
| アイデア | 思いつきを書き留める付箋 |
| Web ページ | URL を埋め込み表示。YouTube などは再生可能な埋め込みに自動変換 |
| PDF | ページ送り・スクロール・見開き表示、ズーム、目次、全画面 |
| 画像 | 非破壊トリミング対応 |
| 動画 | ブックマーク、時間指定リンク、任意フレームを画像カードとして書き出し |
| 音声 | 波形表示、ブックマーク |
| 連番再生 | 複数の画像をパラパラ再生（オニオンスキン付き） |
| スケッチ | スケッチページの内容を読み取り専用で表示（ライブ更新） |
| 路線図 | 路線図ページのプランを読み取り専用で表示（ライブ更新） |
| タスク下書き | あとでまとめてタスク化する下書き（[詳細](./task-draft)） |
| キャンバスリンク | 別タブへのショートカット。クリックで移動、プレビュー付き |
| シェイプ | 構成図用の図形 14 種（[ツール](./tools#シェイプ図形)） |

::: tip ノート / タスクとの連動
メモカード・TODO カードのヘッダーにあるリンクアイコンから、既存のノートやタスクを選んで**紐づけ**できます。紐づけたカードは元のデータを直接表示し、どちらで編集しても同期します。
:::

## 移動・サイズ変更

カードの**ヘッダーをドラッグ**して移動します。右下の角をドラッグするとサイズ変更です。グリッドスナップをオンにすると 20px 単位に揃います。

![カードの移動](/media/canvas/move-card.gif)

複数のカードを動かしたいときは、背景からドラッグして**範囲選択**するか、`Shift` を押しながらクリックで追加選択します。`Ctrl+A` で全選択です。

## 編集

- **タイトル**: ヘッダーのタイトルをクリックして編集
- **本文**: テキスト系カードの本文をクリックすると Markdown エディタになります。右クリックで記法の挿入メニュー、`Ctrl+B` などのショートカットはノートと共通です
- **色**: カードを選んでツールバーまたは右クリックメニューからパレットを選択（淡色 / 濃色）
- **ロック**: プロパティパネルの「ロック」で移動・編集を禁止（誤操作防止）

## コピー・複製・削除

| 操作 | キー |
| --- | --- |
| コピー / 貼り付け | `Ctrl+C` / `Ctrl+V`（右クリック「ここに貼り付け」で位置指定） |
| 複製 | `Ctrl+D`（少しずらして複製） |
| 削除 | `Delete` / `Backspace`（確認ダイアログあり） |
| 元に戻す | `Ctrl+Z`（削除も戻せます） |

カードはタブをまたいでコピー＆貼り付けできます。

## 整列

複数選択すると、ツールバーに**左揃え / 左右中央 / 右揃え / 上揃え / 上下中央 / 下揃え**が現れます。3 個以上選ぶと**左右 / 上下に均等配置**も使えます。重なり順は「最前面へ」「最背面へ」で変更します。
