# フローの全体像

段取りを**ノードでつないで図にし、そのままタスクにする**ページです。「何を、どの順で、だいたいいつ」を考える段階に向いています。キャンバスのタスク下書きと同じ思想を、接続と時期の指定に特化した専用画面にしたものです。

![フローの全体像](/media/flow/overview.png)

1 つのプロジェクトに複数のフローを持てます（左の一覧）。

## ノードを置く

空いている場所を**ダブルクリック**するとノードが作られ、すぐタイトルを入力できます。

![ダブルクリックでノードを追加](/media/flow/add-node.gif)

ツールバーからは**画像カード**（ファイル選択 / `Ctrl+V` / ドラッグ＆ドロップ）と**メモカード**も置けます。これらは注釈用で、タスクにはなりません。

## キーボードで広げる

ノードを選んで:

| キー | 動作 |
| --- | --- |
| `Tab` | 下に**子**ノードを作ってつなぐ |
| `Enter` | 右に**兄弟**ノードを作る（同じ親につながる） |

![Tab / Enter で連鎖](/media/flow/tab-enter.gif)

`Tab`・`Enter` を押しながらタイトルを打ち込むだけで、ツリーが組み上がります。

## ドラッグでつなぐ

ノード下端の **●** を別のノードへドラッグすると「親 → 子」の矢印になります。空いている場所に落とすと、そこに子ノードが新しく作られます。

![● をドラッグして接続](/media/flow/connect-drag.gif)

## 「大体いつ」を付ける

ノードには時期の目安を付けられます。

![大体いつチップと月ピッカー](/media/flow/when-chips.png)

| 項目 | 内容 |
| --- | --- |
| 月頭 / 初旬 / 中旬 / 下旬 / 月末 | 月内の位置。タスク化のとき具体的な終了日に変換される |
| 月 | 対象の月。未指定なら「今月（過ぎていれば来月）」。年送りもできる |
| 親継承 | 親ノードの日付をそのまま引き継ぐ（子を個別に決めたくないとき） |

## グループ枠

ノードを選んで `Ctrl+G` でグループ枠にまとめられます（`Ctrl+Shift+G` で解除）。枠はドラッグでまとめて移動でき、枠だけ削除してもノードは残ります。

## タスク化する

ツールバーの**タスク化 N**（N は未変換ノード数）で、フロー内のノードをまとめて実タスクに変換します。

![タスク化ダイアログ](/media/flow/convert-dialog.png)

- 追加先のボードを選ぶか、新しいボードを作る
- 矢印（親 → 子）はそのまま**サブタスク**の関係になる
- 「大体いつ」は終了日になる。親継承のノードは親と同じ日付
- 変換は 1 回の操作なので `Ctrl+Z` で丸ごと戻せる

変換後のノードは実タスクと**連動**します。ノードに状態のドット（未着手 / 進行中 / 完了）が表示され、ノード側で状態を変えるとタスクにも反映されます。タスクが削除されるとノードに「リンク切れ」が表示され、「リンクを解除して下書きに戻す」で再び下書きとして使えます。

## 操作一覧

| 操作 | 方法 |
| --- | --- |
| パン / ズーム | `Space`+ドラッグ / `Ctrl`+ホイール・ピンチ、ツールバーの − ＋ 全体表示 |
| 複数選択 | 背景ドラッグで範囲選択、`Ctrl+A` |
| コピー / 貼り付け / 複製 | `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| 移動 | ドラッグ、矢印キー（`Shift` で大きく） |
| 削除 | `Delete` / `Backspace`、右クリックメニュー |
| 取り消し | `Ctrl+Z` / `Ctrl+Y` |
